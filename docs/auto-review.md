# 帮我批准

权限选项为请求批准、帮我批准、完全访问。新 Agent 默认帮我批准；已有 Agent 和任务的保存值不被改写。自动接受编辑、规划和不询问模式仅供历史读取，不再提供选择入口。

帮我批准由支持 auto_review_v1 的 SDK 运行时执行独立模型审核。低风险且授权明确的未决操作可自动通过；高风险、不确定、审核故障或需要真人确认时转人工。审核不保存持续权限，也不覆盖领域授权。当前 MCP 与子 Agent 授权仍由人工处理。旧 nxs 明确提示升级或改选请求批准。切换 Claude 时所有权限入口隐藏帮我批准，已保存的 auto 按请求批准展示与执行，切回 nxs 保留原配置。

系统权限只作为新 Agent 的创建默认值；Agent 独立设置位于底部高级设置，修改不会回写系统，也不随系统后续变化同步。Session 显式覆盖优先；定时任务创建时保存执行 Session/Agent 权限快照，后续变化不追随。

DM 与 Room Thread 保存自动审核结果，Room 公区不展示过程记录。普通权限卡与定时任务持久审批卡显示转人工原因；定时任务仍使用原有暂停、批准和恢复链。

部署需配套新 nxs、包含 auto_review_v1 的 bridge 以及产品；本地多仓 go.work 可联合验证，发布时应先发布 bridge 并更新产品依赖，不能仅发布前端。
