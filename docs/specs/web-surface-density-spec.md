# Web 页面信息层级规范

本文只定义 Nexus Web 主页面的默认信息层级与内容预算；字体、字号、控件几何、材质和交互状态统一以 [design.md](../../design.md) 为当前规范，不在此另设数值。弹窗信息细则见 `dialog-design-spec.md`，能力目录细则见 `capability-page-design-spec.md`；共同原则是先保留支持识别、比较和决策的信息，再按需查看实现与诊断。

## 1. 默认信息预算

一个页面或设置分区的首个可视层回答五件事：

1. 我在哪里；
2. 当前对象是什么；
3. 当前状态是什么；
4. 现在可以做什么。
5. 不同选择或当前异常会带来什么影响。

对象用途、真实摘要、选择差异、触发方式、当前错误和管理对象的身份属于默认层。协议名、内部绑定键、Session key、请求 ID、模型诊断、完整模板和底层路径通常进入展开详情、悬停说明、二级页面或明确的诊断入口；但账号、文件或配对管理页中的 ID 若是区分对象所必需，仍应直接展示。

### 1.1 字体与密度入口

字体与文字角色遵循 [design.md §4](../../design.md#4-字体与排版)，阅读正文遵循其 §6.2。页面的信息预算不能通过任意缩小字号、隐藏必要说明或缩小触控区域达成；业务代码只选择共享文字角色和已有控件密度。

### 1.2 菜单型浮层的空间入口

Action、Select、Mention、Slash、级联选择与上下文菜单共同遵循 [design.md §5.4](../../design.md#54-输入选择器菜单与提示)。业务页面只通过公开参数表达内容需要，不在信息层级规范中重定义浮层样式或高度估算。

## 2. 页面合同

- 页面标题使用稳定名词或明确任务短语，不使用“探索”“解锁”“让 AI 帮你”等宣传句。对于首次接触难以理解的能力，可以保留一句解释其用途的副标题。
- 同一视口只出现一个页面身份。移动端应用栏已经展示分区名称时，内容区不得再用同义 H1 重复一遍。
- 目录条目默认显示名称、真实的一至两行摘要、必要状态、比较事实与主动作；能力与管理目录没有真实摘要时留白，联系人常驻侧栏沿用“暂无描述”维持稳定的双行扫描结构。
- 配置页需要让候选项可比较。会改变权限、行为或后果的差异必须随选项展示；只有完整模板、实现细节和低频诊断可以延后。
- 普通 Agent 身份页中的 AGENTS.md 是用户直接审阅和编辑的行为正文，保持完整可见；协议实现、内部绑定和其他原始配置才默认进入按需详情。
- 空态应说明用户可以怎样创建、连接或调整筛选；不附加推测性原因、宣传文案或重复按钮。
- 错误信息说明当前动作发生了什么以及可执行的恢复方式；不暴露内部服务、堆栈、请求 ID 或笼统的“服务内部错误”。
- 主动作、危险动作和导航动作保持视觉分级；省略号只用于真实的次要动作菜单，不作为页面唯一入口，也不悬空占据标题区。
- 窄屏优先保留对象、状态、选择影响和主动作；页面身份不得重复，但行级决策说明不能仅因屏幕变窄而消失。

## 3. 严重度

- **P0**：阻碍识别、操作或阅读主路径；首屏被重复内容、技术细节或无意义占位占据。
- **P1**：任务可完成，但需要穿过明显的解释墙、重复标题、徽标堆叠或不清晰动作层级。
- **P2**：局部措辞、间距或响应式节奏问题，不改变任务理解。

P0 应在发现阶段直接修复；P1 按领域分阶段收口；P2 与相邻领域改动一并处理。

## 5. 验证

每个阶段至少包含：

- 桌面与窄屏的真实浏览器检查；
- 根元素不覆盖继承字号，正文保持所属 Surface 的阅读字号，页面标题和常规控件符合语义阶梯；
- 关键对象、状态和动作仍可访问；
- 被收起的信息仍可通过明确入口恢复；
- 中英文键集合、lint 与 typecheck 通过；
- 行为测试固定默认层级，既防止长说明和内部字段回流，也防止必要决策信息再次被误删。
