# Web 弹窗设计规范

按任务类型选择弹窗结构与文案。视觉数值以 [`design.md`](../../design.md) 为准；组件所有权、视口/层级实现与验证流程见 [`frontend-engineering-spec.md`](./frontend-engineering-spec.md)；通用页面信息层级与错误文案见 [`web-surface-density-spec.md`](./web-surface-density-spec.md)。

## 入口审计口径

- 产品代码中 `<UiDialogBackdrop>`、`<ConfirmDialog>`、`<PromptDialog>` 的每个声明计为一个可独立出现的模态入口；共享 primitive 和开发 Gallery 自身不计入。
- 未使用上述 primitive、但暴露 `role="dialog"` 或 `aria-modal="true"` 的交互面单独审计，不以名称推断其具备模态行为。
- 新增或移除入口时，更新所属模块的所有权文档，并运行共享模态与所涉业务测试。
- 历史数量只记录审计范围，不能代替当前调用点检查，也不能证明键盘或焦点行为正确。

## 设计语法

### 决策框

- 只保留短标题、具体后果和动作。
- 不自动补“请确认”“立即生效”“不可恢复”等泛化套话；确有不可逆后果时由业务正文说明。
- 危险等级由文案和确认按钮 tone 表达，不使用警告图标、消息卡或重复副标题。
- 二次确认复用共享决策框，不调用浏览器原生 `alert`、`confirm` 或 `prompt`。

### 连接、授权与紧凑表单

- 使用 `UiDialogHeader/Footer appearance="plain"`，标题直接命名目标。
- 首屏只放当前步骤需要的字段、状态和动作；平台教程默认折叠或链接到文档。
- 凭据、二维码和验证码可以使用一个功能性承载面，但不得再嵌套状态卡、隐私宣言或装饰性图标。
- 具体业务错误可以显示；“服务内部错误”等无行动价值的占位消息必须替换为当前操作的短兜底文案。

### 选择器与工作台

- 少量互斥选项使用紧凑列表或分段控制；不为每个选项重复同一段解释。
- 目录型选择器使用普通标题、搜索/筛选和扁平行；不得用装饰图标、副标题、标签胶囊与重复按钮把选项包装成卡片。
- 需要持续浏览、对照或编辑的内容使用工作台布局，不在小弹窗里堆叠标题、教程、表单、画布和双重 footer。
- 桌面可使用双栏；窄屏必须切换为单栏或标签，不允许横向溢出。
- Composer 目录选择器：
  - 优先聚焦搜索，焦点由公共模态入口设置；
  - 连续列表复用公共 Panel 和行样式；动作、分类和命令使用可读 supporting/metadata 层级；
  - 工作图选项只保留一个 Tab 入口，方向键和 Home/End 用于浏览，明确使用动作才写入命令。

### 预览器

- 文件预览只显示文件名；“图片预览”“文本预览”等可从内容判断的类型不重复显示。
- 纯画布预览可不显示标题栏，但必须保留视觉隐藏的可访问名称和独立关闭动作。

### 管理目录与历史

- 首屏只显示对象身份、必要状态和动作；实现原理、适配器教程和内部 ID 不逐项铺开。
- 来源、运行和权限的技术身份进入按需展开的诊断区；真实业务错误保持可见。
- 对象名可以直接作为弹窗标题；“当前状态”“运行历史”“需要处理”等泛化标签不与对象名、副标题和状态图标重复堆叠。
- 会话历史：
  - 时间和选择数量使用公共 metadata；空历史用 supporting 短说明；窄屏时间跟随界面语言；
  - 行内次动作由公共 ListAction 持有鼠标、键盘与无 hover 输入的可见性，外层不能再次隐藏；
  - 批量操作的未确认结果复用 InlineNotice，置于滚动正文，保留底部操作的可达性。

## 可访问性与行为

层级、视口 inset 与 Dialog 高度只通过语义 API 选择，规则见 [frontend-engineering-spec §6.3](./frontend-engineering-spec.md#63-浮层与小窗口)；业务组件不得声明数值 `z-index` 或重复 `dvh`/像素公式。

模态与命名：

- `UiDialogBackdrop` 统一提供焦点陷阱、Escape、背景滚动锁和可访问命名；业务层不得复制 modality。
- 普通弹窗用可见 Header 标题作为可访问名称：`UiDialogHeader.title` 自动关联到最近的 `UiDialogBackdrop`，随当前步骤标题更新。
- 公共层持有实例唯一 ID 和标题注册/释放，业务不重复接线；嵌套弹窗和同名实例各自独立。
- 显式 `labelledBy` / `aria-labelledby` / `aria-label` 优先于自动标题。
- 自定义 Header 内容或无标题栏的预览必须由调用方显式命名，不能从按钮、图标或正文猜测。
- 说明关联由业务指定：只有必要的简短说明才显式关联为描述；复杂正文保留结构阅读，不压成一条可访问描述。

动作语义：

- 关闭、取消业务操作和提交保持不同语义。关闭不能暗中提交或撤销；业务取消必须调用原有控制动作。
- 异步状态原位替换当前动作或显示一行短状态，不新增重复弹窗。

公共输入弹窗（Prompt）：

- 以可见标题或明确的 `inputLabel` 命名字段；placeholder 只作示例。
- 字段错误与多行快捷键说明复用 UiField 的排版和精确关联。
- 默认按钮与快捷键文案跟随语言，业务专用动作优先。
- 写入期间由调用方 busy 同时禁用字段、提交、取消及关闭；公共控件不推断结果。

输入法与键盘：

- 输入法候选 Enter 不触发 Prompt 提交；候选 Escape/Tab 不触发模态或锚定浮层的全局关闭/焦点循环。各事件边界复用唯一 IME 判定，不复制独立标记、延时或键码规则。
- 历史标题内联编辑的 Enter/Escape 同样排除输入法选词。普通 Escape 只退出当前编辑并恢复入口焦点；后续 Escape 继续服从公共浮层的逐层关闭协议。

## 审计状态（non-normative）

历史审计快照覆盖 61 个产品模态根和 5 个 dialog 型浮层（决策框、WorkGraph、Connector、Channel、Agent/Provider/Room 表单、Composer 选择器、附件/Mermaid 预览、Skill/Scheduled 管理、配对、MCP、引导中心、Goal、联系人、CC Switch、Provider 初始化向导；历史、移动端会话切换、模型选择、记忆说明和图标选择浮层）。该数量不是自动维护的当前清单；新增入口按上述合同审计。
