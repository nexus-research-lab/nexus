# Web 能力页面设计规范

能力模块的信息密度与文案合同。通用页面层级、空态与错误规则见 [web-surface-density-spec.md](./web-surface-density-spec.md)，本文只补充能力页特有规则。能力页是管理工具，不是功能宣讲页；帮助识别、比较和决策的用途说明属于工具本身，不能随宣传文案一并删除。

## 当前清单

- 侧栏包含 **6 个能力页面**：技能、连接器、频道、频道配对、定时任务和工作图。
- 连接器下的自定义 MCP 与各能力详情页沿用同一合同，不计为侧栏页面。
- 不提供内置 Loops 模板目录；Composer 通过普通 Goal 或已保存工作图发起任务。
- 新增、移除或改名页面时，同步本节和对应目录的 L2 文档。

## 页面层级

- 页面标题使用可直接定位的名词或任务短语。“管理”“连接”“复用”可说明页面职责，但不能扩写成宣传口号。
- 6 个页面都保留一句用途说明：回答“这里管理的对象会怎样参与工作”，不重复标题，不罗列能力。
- 搜索、筛选和顶部动作紧跟标题；单一目录不重复同名分区标题或结果总数。
- 分类、状态、渠道、来源与 Agent 的下拉筛选复用全产品 `UiFilterSelect`（结构、密度与宽度见 [design.md](../../design.md)），不另定义能力域版本。
- 分类标题只用于真实分组。数量只在待处理、按 Agent 分组或看板状态等需要快速判断规模时展示。

## 目录条目

- 首屏显示对象身份、必要状态、真实用途摘要和当前决策需要的元数据；摘要可占一至两行，不能为统一高度删掉关键差异。
- 保留在目录（直接影响选择）：Skill 用途、Channel 用途、定时任务指令摘要、WorkGraph 的内置模板/owner 保存来源语义、配对的外部对象身份。
- 不进入目录：Connector/Channel 的协议实现、定时任务完整指令、WorkGraph 运行历史、内部绑定身份。
- WorkGraph：内置模板只读，只提供查看、复制 Slash 与复用；owner 保存图继续提供编辑与删除。
- 自定义 MCP 目录使用与 WorkGraph 相同的 seeded 曲线图标；条目直接提供 owner 开关。关闭后仍保留在管理目录，但不出现在对话选择中。
- 历史自定义 MCP 的加密配置若无法由当前宿主密钥读取：
  - 目录保留稳定的“待恢复”条目，不得显示为空或拖垮标准 Connector；
  - 该条目关闭对话开关和工具发现，只允许删除或进入完整重新配置；
  - 保存后沿用原 Connector 身份。
- 对象所属分组已由上级标题表达时，卡片不重复解释；手动触发等默认事实不作为常驻元数据。
- 原始 ID、Session key、绑定键、命令参数和诊断内容只进入详情、编辑面或显式展开的技术区。外部账号或配对 ID 若是被管理对象的唯一身份，作为业务身份直接显示。

## 空态与错误

通用空态与错误规则见 [web-surface-density-spec §2](./web-surface-density-spec.md#2-页面合同)。能力页补充：

- 搜索无结果只显示短结论；可保留清除筛选动作，不附加“试试其他关键词”一类提示。
- 真正空目录可以提供一个创建动作、一句必要前置条件或来源说明；轻量图标可帮助定位空态，但不使用教学卡片或多段能力介绍。
- 看板空列由列名和数量 `0` 自解释，不在每列重复“当前没有……”的图标和句子。
- 真实错误与恢复动作保持可见；协议名和不可执行的诊断文字不得替代用户可采取的下一步。

## 详情与响应式

通用详情：

- 详情页可展示完整说明、步骤和能力范围；摘要不与正文重复，统计和默认状态不堆叠成徽标墙。
- 能力范围列表用名称、状态、用途和开关表达；系统托管、主智能体、不可配置等会改变行为的差异必须逐项说明。

连接器准备步骤：

- 使用中性公共信息面板和自然换行正文，不把整句操作提示做成状态徽标。
- 能力行复用公共紧凑列表，不在每项前重复成功图标。
- 页面自有动作和说明随当前语言切换；第三方应用菜单名与服务端能力正文保持准确原文。
- 没有服务端有效期事实时，不用固定天数推测 Token 到期时间。

自定义 MCP 详情：

- 扁平子页面层级，展示脱敏连接信息、服务器初始化信息与工具目录。
- 工具名、描述和参数 schema 以 MCP `tools/list` 返回为准；只读标记直接投影对应 annotation。
- 可以折叠长文本，但不得改写服务端说明（例如 description 中的阶段标签原样保留）。
- 不展示 Prompts/Resources；stdio 详情不以宿主身份执行用户命令。
- 待恢复详情不伪造名称、连接地址、认证方式或工具，只说明历史记录仍被保留，并提供唯一的完整重新配置动作。

RichMail（固定 Connector，同一扁平详情语法）：

- 未连接时：
  - 先提示打开 RichMail 并保持后台运行；
  - 给出准备路径“设置 → Rwork → 智能体与能力 → 对外 MCP 服务 → 启用 Agent MCP 服务”；
  - 再说明无 Token 请求、客户端批准和自动保存阶段。
- 无法访问本机服务时复用同一恢复路径，不显示通用 OAuth 窗口文案。
- 已连接时展示固定 loopback 地址、传输、脱敏认证状态、服务器身份、协议版本与实时工具目录。
- Token、Provider request ID 和认证 header 永不显示；Prompts/Resources 不进入页面。

WorkGraph 详情：

- 能力详情与保存确认对话框复用同一套完整预览画布，只由消费面调整高度。
- 能力详情画布填满标题、搜索与目标摘要之后的剩余高度；窄屏不足时保留最小可操作高度并由页面滚动。
- 预览节点默认展示标题、两行工作目标和“必需/最终交付”等关键标记；完整交付与验收信息通过节点详情查看。

响应式：

- 桌面目录保持三列，定时任务保持四列关系；窄屏按既有响应式协议收拢或横向滚动，不以增加说明文字补偿布局变化。
- 手机宽度由应用返回栏提供页面身份；能力正文不重复同名标题或独立动作行，但保留一行用途说明。
- 页面级动作进入返回栏标题右侧，空间不足时收拢为紧凑入口。
