# Web 能力页面设计规范

本文记录 Nexus Web 能力模块当前的信息密度与文案合同。能力页是管理工具，不是功能宣讲页；但帮助用户识别、比较和决策的用途说明属于工具本身，不能与宣传文案一并删除。

## 当前清单

侧栏当前包含 **7 个能力页面**：技能、连接器、频道、频道配对、定时任务、工作循环和工作图。连接器下的自定义 MCP 与各能力详情页沿用同一合同，但不重复计为侧栏页面。

新增、移除或改名时，必须同步本节、`web/scripts/capability-page-density.test.mjs` 和对应目录的 L2 文档。

## 页面层级

- 页面标题使用可直接定位的名词或任务短语。“管理”“连接”“复用”可以用于说明页面职责，但不能扩写成生成式宣传口号。
- 技能、连接器、频道、频道配对、定时任务、工作循环和工作图都保留一句用途说明；它回答“这里管理的对象会怎样参与工作”，不重复标题或罗列能力。
- 搜索、筛选和顶部动作紧跟标题；单一目录不得再重复同名分区标题或结果总数。
- 分类标题只用于真实分组。数量只有在待处理、按 Agent 分组或看板状态等需要快速判断规模时展示。

## 目录条目

- 首屏显示对象身份、必要状态、真实用途摘要和当前决策需要的元数据；一般摘要可占一至两行，不能为了统一高度删掉关键差异。
- Skill 用途、Loop 触发方式、Channel 用途、定时任务指令摘要、WorkGraph 来源语义和配对的外部对象身份会直接影响选择，因此保留在目录。
- Connector/Channel 的协议实现、定时任务完整指令、WorkGraph 运行历史和内部绑定身份不进入目录。
- 对象所属分组已由上级标题表达时，卡片不重复解释；手动触发等默认事实也不作为常驻元数据。
- 原始 ID、Session key、绑定键、命令参数和诊断内容通常只进入详情、编辑面或显式展开的技术区。外部账号或配对 ID 若是被管理对象的唯一身份，则作为业务身份直接显示；内部 Session 和绑定键仍延后。

## 空态与错误

- 搜索无结果只显示短结论；清除筛选动作可以保留，不附加“试试其他关键词”一类同义提示。
- 真正空目录可以提供一个创建动作、一句必要前置条件或来源说明；轻量图标可以帮助定位空态，但不使用教学卡片或多段能力介绍。
- 看板空列由列名和数量 `0` 自解释，不在每列中央重复“当前没有……”的图标和句子。
- 真实错误与恢复动作保持可见；内部错误、协议名和不可执行的诊断文字不得替代用户可采取的下一步。

## 详情与响应式

- 详情页可以展示完整说明、步骤和能力范围，但摘要不与正文重复，统计和默认状态不堆叠成徽标墙。
- 能力范围列表用名称、状态、用途和开关表达。系统托管、主智能体、不可配置等会改变行为的差异必须逐项说明。
- 桌面目录保持三列，定时任务保持四列关系；窄屏按既有响应式协议收拢或横向滚动，不以增加说明文字补偿布局变化。
- 手机宽度由应用返回栏提供页面身份；能力正文不重复同名标题或独立动作行，但保留一行用途说明。页面级动作进入返回栏标题右侧，并在空间不足时收拢为紧凑入口。

## 审计状态（non-normative）

当前 7 个侧栏页面及连接器、Skill、Loop 和 WorkGraph 主要详情面已完成本轮复核：用途说明、真实摘要、触发方式、任务指令摘要和外部配对身份恢复到默认层；重复分区、装饰性计数、看板空列说明、协议实现与内部绑定身份继续延后。
