# 桌面沙箱与一次性审批

Nexus 桌面端在受限权限模式下，会把 Agent 的命令和文件操作放进 nxs 的本机沙箱。工作区内的普通操作按当前权限规则执行；越过工作区的操作不会通过修改 Agent 设置来放行。

需要额外能力时，审批分为三类：Bash/PowerShell 执行沙箱外命令，Write/Edit 写入工作区外的普通文件，以及命令或图片/网络工具连接未批准的网络目标。Nexus 会在真正执行前暂停当前动作，并显示工具、目标、执行目录和风险说明。

选择“允许本次”后，只允许当前审核过的精确动作完成。文件操作的临时授权只在当前 helper 调用期间有效，并覆盖该操作所需的同目录原子暂存；它不会变成用户可见的目录白名单。网络授权只覆盖当前待连接目标。下一次写入其他文件或连接其他目标仍需重新审批。

这次批准不会把目录加入白名单，不会修改 Agent 的权限设置，也不会让 Agent 获得修改沙箱策略的能力。用户拒绝后，操作保持被沙箱拦截。隐藏目录、符号链接指向的路径、只读资源和 Nexus 自身受保护目录仍然拒绝。Read、Glob、Grep、ViewImage 等读取工具按读取审核规则处理，不等于获得写入权限。

如果用户需要长期扩大会话的文件范围，应由用户主动切换权限模式。Full Access 表示用户明确选择不要求桌面沙箱隔离，但仍受操作系统账户权限、Nexus 业务授权和运行时生命周期约束。
