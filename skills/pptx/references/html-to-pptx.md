# HTML 布局生成

HTML-to-PPTX 适合从零创建版式密集的演示文稿，不适合直接改写一个已有模板的内部结构。它把 HTML/CSS 当作布局草稿，再把页面转换为 PowerPoint 图形；最终文件仍需按 PPTX 逐页检查。

## 设计约束

- 固定页面比例和尺寸，默认使用 16:9（720×405pt）；不要让每页自行决定画布。
- 只使用转换器明确支持的文本、矩形、图片、线条和简单 SVG。复杂 CSS、渐变、阴影和图标需要先降级或栅格化。
- 页面内保留安全边距；不要把文字放到靠近边界的位置来“碰运气”解决溢出。
- 使用系统中已有的通用字体。字体缺失会改变换行和页面高度，不能在生成后才处理。
- 图表和表格如果需要后续编辑，应在转换后用 `python-pptx` 或原生 PowerPoint 图表重新确认；截图式图表只能作为视觉备选。

## 推荐流程

1. 先写页面大纲和每页主结论，再为每页创建独立 HTML。
2. 用当前环境已有的转换器生成临时 PPTX；不在 Skill 执行期间静默安装 Node、浏览器、字体或全局 npm 包。
3. 运行 `validate_presentation.py`，确认 ZIP、XML 和内部关系没有损坏。
4. 运行 `render_presentation.py`，逐页检查换行、裁切、重叠、对比度和图表标签。
5. 若需要修改，回到 HTML 的尺寸、间距和字体处理；不要靠不断缩小字号压缩内容。

如果环境没有可用的 HTML-to-PPTX 转换器，使用 `python-pptx` 新建文件，并在交付说明中说明采用了回退路径。
