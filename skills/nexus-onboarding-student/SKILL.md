# 学生新手引导

用真实对话完成两个里程碑：创建学习 Agent；创建小组作业或学习协作 Room 并进入协作。不要将用户输入硬编码映射为动作。

开始收集信息前必须加载 `nexus-onboarding-card-kit`。Agent 名称、职责、风格、创建确认、Room 任务、成员确认和 Room 创建确认必须依次调用预置卡片；禁止用普通文本问题代替。名称候选使用“学习搭档”“知识罗盘”“作业教练”，职责候选使用“课程学习规划”“资料整理与研究”“作业检查与讲解”，风格候选使用“循序渐进”“目标导向”“启发式讲解”。Room 任务候选使用“小组作业协作”“考试复习规划”“课题资料研究”。卡片超时后保留当前步骤，不得降级为文本追问。

启动消息会声明这是一次全新的旅程。只用当前会话中的卡片答案和创建结果恢复进度；查询真实 Agent 和 Room 只能校验资源，历史资源不得自动算作本次已完成或导致跳过卡片。通过预置卡片逐步收集 Agent 名称、课程或学习目标、希望获得的产出。加载 `nexus-manager` 后，在用户通过创建确认卡片后调用 `nexusctl --json agent create` 真实创建，并写入 `--vibe-tag`。

第二个任务通过 Room 任务卡片收集一个真实课程主题、作业或学习难题，建议由用户的学习 Agent、资料研究伙伴、检查与讲解伙伴协作。通过成员与最终确认卡片后复用已有 Agent、创建缺失成员。创建 Room 时必须从 `agent list` 找到 `is_main=true` 的 Nexus 主页 Agent，把它连同三位协作 Agent 加入成员，并使用 `--host-agent-id`、`--allow-main-agent-host`、`--host-auto-reply-enabled` 设为主持人；用 `--initial-message` 携带包含真实学习主题和分工的预置开场（换行写作字面量 `\n`），用重复的 `--initial-target-agent-id` 只定向资料研究伙伴和检查与讲解伙伴。创建“小组作业协作室”或更贴合主题的 Room。创建成功必须由卡片套件的模板 H 收口：保留真实 `room create` 结果供 Nexus 渲染预定义可点击卡片，不要追加查询命令补卡片，也不要手写假卡片。进入 Room 后由 Nexus 主持人自动发出开场，后续输出由 Room 真实模型服务完成；此时才完成引导。

每轮只推进一个步骤；不重复询问已知信息；工具失败时如实反馈；系统问题优先解决后再继续任务。
