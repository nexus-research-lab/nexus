# 浏览器能力

## 能做什么

连接后，智能体可以在用户当前电脑上的 Chrome 或 Edge 中：

- 打开网页、切换标签、前进后退和查看历史。
- 读取页面内容。
- 点击、填写、勾选、选择、滚动、拖动和使用键盘。
- 上传文件、处理下载、截图或保存页面 PDF。
- 在用户允许的范围内查看页面报错、网络请求和弹窗。

它使用用户现有浏览器和已经登录的账号，因此可以处理必须登录后才能看到的页面。也正因为如此，操作可能接触敏感账号和数据，应对发布、付款、删除、发送消息等高影响操作再次确认。

浏览器能力不是连接器。浏览器像用户一样操作网页；连接器通过外部服务提供的专门接口访问内容。

## 安装和连接

当前只支持桌面端安装。

入口：设置 → 浏览器 → 开始安装。

Nexus 会打开 Chrome 或 Edge 的扩展管理页，并在本机显示已经打包好的扩展文件夹。然后：

1. 在浏览器扩展页开启“开发者模式”。
2. 选择“加载已解压的扩展程序”。
3. 选择 Nexus 显示的扩展文件夹。
4. 返回 Nexus，等待状态变成“已连接”。

设置页会显示未连接、已连接或版本不兼容等状态。已连接时还能看到扩展版本。一次只保留一个有效的浏览器扩展连接。

## 怎么使用

连接成功后，不需要先打开一个专门的浏览器页面。直接在单人聊天或多人房间中说明要做什么，例如：

- “打开这个网址，帮我总结主要内容。”
- “在当前已登录的后台找到昨天的订单，不要做修改。”
- “把这个表单填好，提交前让我确认。”
- “下载报告并放到当前工作区。”

智能体控制的标签页按当前会话和这次工作隔离。为临时任务打开的标签页可能在本轮结束时关闭；需要保留给用户继续查看时，应明确要求保留或交还。

智能体正在操作的页面会显示 Nexus 指针，帮助用户看清它准备点击的位置。

## 从浏览器把内容交给 Nexus

浏览器扩展菜单中的“Ask Nexus”可以把当前页面、选中的文字、链接或图片带到 Nexus 启动页。

这个动作只会预填输入框，不会自动发送。用户仍然可以检查内容、选择智能体或房间，再决定是否发送。

## 更深层的浏览器控制

设置页提供一个默认关闭的高级开关，用于更深层的浏览器调试和控制。普通的网页阅读、点击和填写不需要开启。

只有高级调试确实需要时再开启，因为它能接触更完整的浏览器内部信息和操作范围。向普通用户说明风险即可；只有用户追问技术细节时再解释 CDP 这个名称。

## 常见问题

- 看不到安装入口：先确认正在使用 Nexus 桌面端，而不是普通网页。
- 一直未连接：确认扩展已加载、已启用，而且版本没有提示不兼容。
- 网页操作失败：先确认目标标签仍存在、页面没有退出登录，并检查是否出现需要用户处理的验证码、弹窗或权限确认。
- “Ask Nexus”后没有运行：这是正常行为，它只负责带入内容，用户还需要在启动页发送。
- 已配置连接器但不能控制网页：连接器与浏览器是两项独立能力，需要单独安装浏览器扩展。
