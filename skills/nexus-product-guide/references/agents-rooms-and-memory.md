# 智能体、房间与记忆

## 智能体是什么

智能体是一位可以长期配置的 AI 助手。不同智能体可以使用不同的名称、角色说明、模型、Skill、工具权限和连接器，适合承担不同类型的工作。

入口：左侧“联系人”进入“智能体管理”。这里可以创建智能体、比较已有智能体、打开单独聊天，或选择成员发起多人房间。

智能体详情分为：

- 身份：名称、头像、风格标签、模型、简介和长期行为说明。
- Skill：长期启用哪些专门能力。
- 记忆：查看和维护它保存的长期信息。
- 工具：默认权限、允许使用的工具和默认连接器。
- 联络：以这个智能体的身份查看并联系它的智能体好友。

Nexus 主智能体是用户的默认管理助手，可以帮助理解和管理自己名下的资源。它不是普通房间成员，也不会自动绕过确认或权限限制。

## 单人聊天与多人房间

| 方式 | 适合什么情况 |
| --- | --- |
| 单人聊天 | 只需要一位智能体连续处理，讨论更私密、更直接 |
| 多人房间 | 需要多位长期存在的智能体公开讨论、分工或互相协调 |
| 临时子任务 | 只想把当前任务的一小块临时交给另一个执行者，不需要建立长期房间 |

普通单人聊天和多人房间都从左侧“聊天”进入，不从智能体详情里的“联络”进入。

## 创建和管理房间

创建房间时可以设置名称、头像和成员，并选择一位“群主”。还可以决定：

- 用户没有 `@` 任何成员时，是否由群主接管、回答或协调。
- 是否允许房间成员通过私信方式协作。
- 这个房间可以使用哪些 Skill。

房间管理页可以增减成员、调整群主，并暂停或恢复某个成员参与。具体操作会影响后续消息，不应把“暂停参与”说成删除智能体。

## 在房间里找谁回答

- 使用 `@智能体名称` 可以明确指定成员。
- 开启群主自动接管后，不使用 `@` 时群主也可以判断是自己回答还是协调其他成员。
- 如果没有指定成员，而且房间也没有可接管的人，消息可能被记录，但不会启动智能体工作。

房间里的“群主自动接管”和“主动跟进”是两项不同功能。前者决定一条新消息由谁处理；后者是在单人聊天安静一段时间后，系统判断是否值得主动回访。

## 房间中的几个页面

- 工作图：查看当前和过去的任务拆分、先后关系、负责人、结果和交付证据。
- 临时子任务：查看当前回复过程中临时交出的工作；没有发生时可能是空的。
- 工作区：查看成员正在处理的文件和更新。
- 关于：查看房间或当前智能体的身份与上下文信息。

点击某位智能体的回复可以打开对应 Thread。Thread 用于查看详细过程和围绕这条回复继续讨论，不会让公共聊天被大量过程信息淹没。

## 工作区文件

房间工作区支持查看文件列表和预览内容。用户还可以上传文件、新建文件或文件夹、重命名和删除，并把文件加入聊天。

桌面端还可以用本机应用打开文件、选择打开方式或复制路径。网页端不应显示这些依赖本机系统的操作。

删除、覆盖或移动文件会改变真实工作内容，执行前应说明目标和影响。

## 智能体记忆

智能体运行过后，可以把值得长期保留的信息写入自己的记忆。入口：联系人 → 选择智能体 → 记忆。

这里可以：

- 浏览、搜索和筛选记忆文件。
- 打开并阅读完整内容。
- 编辑后保存。
- 删除 `memory/` 目录下不再需要的记忆文档。

记忆首页主要展示方便浏览的内容，较旧内容可能被标记为需要整理。总索引不能像普通记忆文档一样直接删除。

新建但从未运行的智能体可能暂时还没有记忆文件。会话历史和长期记忆不是一回事：删除一段聊天不等于自动删除智能体记忆，编辑记忆也不会改写过去的聊天记录。

## “联络”是什么

“联络”站在某个普通智能体的视角，展示它的智能体好友：

- 可以搜索或添加同一用户下的其他普通智能体为好友。
- 可以查看这些好友之间的私信记录，并代当前智能体发送消息。
- 第一次发消息时，系统会自动建立这对好友的私下沟通空间。
- 删除好友关系不会删除已经形成的消息历史；以后重新添加时可以恢复原来的沟通记录。

普通多人房间仍在“聊天”里，不会重复出现在“联络”页。当前版本不支持跨用户添加智能体好友，Nexus 主智能体也不进入普通智能体通讯录。
