# 开始使用与主要入口

## 登录和退出

需要账号登录的网页会先显示“登录 Nexus”，使用用户名和密码进入工作台。如果当前部署使用其他登录方式，页面会说明这里不能直接使用密码登录，应按管理员提供的方式进入。

“退出登录”只会在网页端已经通过密码登录时显示。桌面端、单用户免登录环境或使用访问令牌的环境不会显示一个无效的退出入口。

## 第一次打开

如果还没有可用的模型服务，Nexus 会先引导用户完成连接：选择服务、填写密钥、验证连接，再选择默认模型。也可以添加自定义服务；界面提供时，还可以从 CC Switch 导入已有配置。

密钥属于敏感信息。引导用户在设置页填写，不要让用户把完整密钥发到聊天中。

完成后进入启动页。新用户最短的开始方式是：

1. 在中间输入想完成的事情。
2. 用 `@` 选择一个智能体，或用 `#` 选择一个多人房间。
3. 发送后进入对应聊天。

“交给 Nexus”会把事情交给 Nexus 主智能体；“进入工作台”会直接打开完整工作区。

## 启动页能做什么

- 继续最近的单人聊天或多人房间。
- 输入一个新问题或新任务。
- 用 `@` 选择智能体，用 `#` 选择房间。
- 从其他页面或浏览器扩展带入文字时，启动页只会预填输入框，不会自动发送，也不会替用户选择智能体。

## 首次欢迎语

用户第一次打开一段单人聊天或创建多人房间时，会看到一条简短欢迎语。它除了介绍当前智能体或房间的沟通方式，也会告诉用户：如果不知道 Nexus 某项功能能做什么、入口在哪里或怎么使用，可以直接继续询问。

多人房间会遵守当前的消息规则。群主已开启自动接管时可以直接提问；否则欢迎语会提醒用户用 `@智能体名称` 指定一位成员。

## 左侧主要入口

| 入口 | 用来做什么 |
| --- | --- |
| 聊天 | 和智能体单独沟通，或进入多人房间协作 |
| 联系人 | 创建、比较和配置智能体，也可以从某个智能体的视角与好友联络 |
| Skill | 查看 Nexus 和智能体可以使用的专门能力 |
| 工作循环 | 查看并启动可重复使用的工作流程 |
| 工作图 | 查看保存过的任务模板，并继续调整或复用 |
| 连接器 | 连接外部服务，让智能体读取或操作其中的内容 |
| 定时任务 | 让任务按时间自动执行，并查看运行记录 |
| 消息通道 | 接入外部聊天软件的账号或机器人 |
| 配对 | 决定外部聊天中的哪个人或群由哪个智能体处理 |
| 指南中心 | 重新查看基础或进阶功能引导 |
| 设置 | 修改界面、模型、权限、浏览器、数据目录等 |

有些入口会根据权限、运行环境或是否完成配置而显示不同内容。例如管理后台通常只对有管理权限的用户开放。

## 固定常用会话

固定会话适合把经常返回的聊天放在左侧，像浏览器书签一样快速打开。

入口：打开聊天后，在顶部的会话标签上点击固定图标。

固定后：

- 会话会出现在左侧能力目录下方。
- 点击可直接打开。
- 可以拖动调整顺序。
- 点击固定项上的关闭图标只是取消固定，不会删除聊天记录，也不会关闭当前会话。

取消固定不会删除会话。删除会话时，对应的固定项会一起移除。固定顺序目前保存在当前客户端中，不应向用户承诺会在不同浏览器或设备之间自动同步。

## 会话标签

顶部会话标签的使用方式接近浏览器标签页：

- “新会话”会创建一段独立聊天，之前的上下文不会自动带入。
- 关闭标签页只是把它从当前工作区收起，不等于删除历史记录。
- 需要重新打开时，从会话历史中选择即可。

## 指南中心

指南中心可以重新查看产品引导。当前引导覆盖启动页、侧边栏、单人聊天、多人房间、Skill，以及 Goal、工作图、临时子任务、Thread、定时任务、连接器和模型服务等进阶功能。

如果首次引导被跳过，可以从指南中心重新开始；设置的“常规”页也提供重置引导进度的入口。

## 桌面端与网页端

大部分聊天和管理功能两端都能使用。下面这些能力依赖桌面端：

- 安装并连接本机 Chrome 或 Edge 的 Nexus 浏览器扩展。
- 给当前会话挂载多个本地工作文件夹。
- 迁移 Nexus 的完整数据目录并重启应用。
- 使用系统应用打开工作区文件、复制本机路径等桌面操作。

回答入口问题时，应先确认用户正在使用桌面端还是网页端。
