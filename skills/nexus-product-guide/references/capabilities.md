# Skill、工作循环、连接器与外部消息

## Skill

Skill 是给智能体准备的专门使用说明和工作方法。例如，一个 Skill 可以教智能体如何管理 Goal、操作某类文件或按固定标准完成工作。

入口分为两处：

- 左侧“Skill”：查看整个 Nexus 中可用的 Skill、来源和更新。
- 联系人 → 选择智能体 → Skill：决定这个智能体长期启用哪些 Skill。

多人房间也可以在房间设置中选择可用 Skill。平台必须使用的系统 Skill 会显示为锁定，不能像普通 Skill 一样关闭。

Skill 库支持搜索、筛选和查看详情。界面提供时，还可以从本地压缩包、Git 地址或社区来源导入，并管理自定义来源和更新。

在聊天中输入 `/skills`，可以为当前请求临时选择一个可用 Skill。这样只影响这次使用，不会自动改变智能体的长期启用设置。

## 工作循环

工作循环是一套可以重复启动的工作步骤，适合检查、改进、再检查这类需要多轮推进的事情。

入口：左侧“工作循环”。详情中可以看到步骤、结束条件、安全限制、启动语句、最多循环次数和标签等信息。

使用方式：

- 复制工作循环提供的启动语句，在聊天中发送。
- 或从输入框的添加菜单选择“启动工作循环”。

工作循环负责“反复按什么方法做”，定时任务负责“什么时候自动做”。不要把两者混在一起。

当前手册只承诺查看和启动界面已经提供的工作循环；不要在未确认入口时告诉用户可以自行创建或编辑工作循环。

## 连接器

连接器把外部服务中的数据或操作接入 Nexus。例如连接文档、项目管理或其他业务服务后，智能体可以在得到权限的情况下使用其中的内容。

入口：左侧“连接器”。这里可以查看连接状态、连接或断开服务，并完成相应登录授权。

连接成功不等于所有智能体和会话都会自动使用：

- 可以在智能体的“工具”页设置默认连接器。
- 当前会话也可以从输入框的添加菜单启用或调整。
- 真正执行外部操作时，仍受当前会话权限和服务本身权限限制。

断开连接器会影响依赖它的后续任务。外部写入、发送、删除或付费操作前，应说明目标和影响并等待确认。

## 消息通道

消息通道用于接入外部聊天软件中的账号或机器人，让外部消息能够进入 Nexus，并让结果可以回到原来的聊天中。

入口：左侧“消息通道”。这里配置平台账号、连接状态以及负责处理消息的智能体等信息。

消息通道解决的是“Nexus 能否连接这个外部聊天平台”，还不能单独决定某个外部用户或群由谁处理。

## 配对

配对把外部聊天中的具体用户或群，与 Nexus 中真实存在的智能体和会话对应起来。

入口：左侧“配对”。外部用户或群第一次发消息后，可能先出现在待处理列表；界面支持时也可以手动添加。用户确认后，后续消息才会按这个关系进入正确的智能体和会话。

三者的关系是：

1. 消息通道已经连接。
2. 外部用户或群已经完成配对。
3. 对应智能体和会话仍然有效，并拥有本次操作需要的权限。

缺少任何一步，都可能出现“通道已连接但消息没有被处理”的情况。

外部聊天中的权限确认只对准确配对的那段对话有效，不会因为同一个账号下还有其他群或私聊就自动共享。

## 相近功能怎么区分

| 需求 | 功能 |
| --- | --- |
| 教智能体一套专门方法 | Skill |
| 重复执行一套有结束条件的工作步骤 | 工作循环 |
| 按固定时间自动运行 | 定时任务 |
| 访问外部服务的数据或操作 | 连接器 |
| 接入外部聊天软件的账号或机器人 | 消息通道 |
| 决定某个外部用户或群由谁处理 | 配对 |
| 操作当前电脑上已登录的网页 | 浏览器能力 |
