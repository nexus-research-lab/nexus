# 会话、消息与输入框

## 会话是什么

一段会话就是一段独立聊天。新建会话后，智能体不会自动知道另一段聊天里的临时上下文；长期保存的智能体记忆属于另一项能力。

会话历史可以用来切换、重命名或删除聊天。界面也提供选择多条、批量删除或清理历史的操作，但外部聊天软件带入的会话不能批量删除，部分系统会话也不会提供删除操作。

关闭顶部标签只会收起，不会删除历史。删除会话会移除对应历史和固定入口，执行前应提醒用户确认。

## 输入框能做什么

普通聊天中可以：

- 输入文字并发送。
- 添加文件附件；当前界面提示单个附件最大 20 MB。
- 在桌面端挂载多个本地工作文件夹，让当前会话在这些位置工作。
- 选择 Goal、工作循环或保存过的工作图。
- 调整当前会话使用的模型、权限和连接器。
- 输入 `/` 查看当前可用的快捷命令。

切换会话时，尚未发送的草稿按会话分别保留，避免把内容带到错误的聊天。不要把这种当前客户端的草稿保留说成跨设备同步。

设定 Goal 时，输入框用于目标本身，不能同时添加普通附件。

## 当前会话的模型、权限和连接器

- 模型和权限可以为当前会话单独选择；没有单独设置时，沿用智能体的默认配置。
- 连接器可以在智能体层面默认启用，也可以在当前会话的添加菜单中调整。
- 修改权限会影响智能体能否直接执行操作、是否需要询问用户，不只是改变回答语气。
- 多人房间里的模型选择针对某个成员智能体，不代表选择了下一条消息一定由谁回答。

## 新消息到来时怎么处理

智能体还在工作时继续发送消息，系统会按“常规设置”里的默认方式处理：

- 排队：等当前回复完成后再处理。
- 打断：停止当前回复，转而处理新消息。

排队中的消息可以调整顺序或删除，也可以标成“补充要求”，让它作为下一轮工作的额外说明。回答用户时使用“排队”“打断”“补充要求”，不需要解释内部队列名称。

## 消息上的常用操作

- 用户消息可以复制。最后一条普通用户消息通常可以编辑或重新运行；Goal 消息不提供普通编辑。
- 智能体已经完成的回复可以复制。
- “分支到新聊天”会从这条回复另开一段聊天，适合沿着不同方向继续，同时保留原聊天。
- 智能体正在回复时可以停止；键盘可用时也可以按 Esc。

单人聊天中，工作过程可以展开查看。多人房间的公共聊天会保持简洁，详细过程和围绕某条回复的讨论放在对应的 Thread 中。最终答复会单独保留，不会被过程信息替代。

当智能体需要用户确认权限、回答问题或确认计划时，输入区会临时显示对应操作。处理完成后，原来的草稿输入会恢复。

## 常用快捷命令

输入 `/` 可以查看当前提供的命令：

| 命令 | 用途 |
| --- | --- |
| `/compact` | 压缩较长聊天的上下文，为后续交流腾出空间 |
| `/model` | 选择模型，并更新该智能体在 Nexus 中明确使用的模型配置；正在运行的会话会在下一轮应用 |
| `/skills` | 打开 Skill 选择器，把选中的 Skill 命令加入输入框；这次使用不会改变长期启用设置 |
| `/visualize` | 请求用可交互界面、图表或其他视觉方式展示结果 |
| `/workgraph` | 为当前请求建立一张新的工作图，帮助拆分和跟踪任务 |

保存过的工作图也会以自己的 `/命令` 出现在可用列表中。每次使用都会建立一份新的任务实例，不会继续修改以前的执行记录。

手动输入的其他运行环境命令可能仍能转交处理，但没有出现在补全列表中的命令不应作为 Nexus 当前产品功能推荐。

## 附件与工作区文件的区别

- 附件是随当前消息一起交给智能体的文件。
- 工作区是智能体持续处理文件的位置，多人房间可以在“工作区”页查看文件和变化。
- 桌面端挂载本地文件夹，是给当前会话增加可工作的本机位置，不等于把整个文件夹作为一条消息上传。

遇到敏感文件时，应先说明可能的读取或修改范围，再让用户确认权限。
