# 设置、账号与排查

## 设置入口

从左侧底部打开“设置”。页面按下面几类组织：

| 页面 | 主要内容 |
| --- | --- |
| 常规 | 诊断、情绪表达、主动跟进、默认模型、消息排队方式、重置功能引导 |
| 运行环境 | 智能体运行内核、工具发现方式和网页搜索服务 |
| 外观 | 主题和界面语言 |
| 数据目录 | 查看或迁移 Nexus 保存数据的位置 |
| 权限 | 新建智能体默认采用的权限方式 |
| 浏览器 | 安装浏览器扩展、查看连接状态和高级控制开关 |
| 个人 | 头像、个人资料、账号信息、用量和密码等可用项目 |
| 模型服务 | 添加服务、测试连接、管理模型和选择默认模型 |
| 管理后台 | 用户、方案、共享模型服务和项目权限；只对有权限的账号显示 |

## 常规设置

常规页包含：

- 诊断信息开关。
- 智能体情绪表达系统，默认关闭。
- 主动跟进总开关，默认关闭。
- 默认聊天、图片、视觉理解和后台任务模型。
- 智能体忙碌时，新消息默认排队还是打断。
- 重置首次使用引导，让指南重新出现。

默认模型是产品的常用选择；某个智能体或会话仍可能有自己的明确设置。回答“为什么这段聊天没有用默认模型”时，应继续检查智能体和当前会话，而不是只看常规页。

## 运行环境与网页搜索

运行环境页用于选择智能体使用的运行内核，控制是否按需发现工具，并设置网页搜索服务。

当前界面支持配置多个网页搜索提供方。不同服务需要不同的地址、密钥或选项。让用户在设置页填写密钥，不要要求用户在聊天里粘贴完整密钥。

网页搜索和浏览器能力不同：网页搜索用于查找公开网络信息；浏览器能力用于操作用户本机已经登录的 Chrome 或 Edge 页面。

## 外观

外观页可以调整主题和界面语言。它只改变显示方式，不会改动智能体的模型、记忆或聊天内容。

## 数据目录

数据目录包含 Nexus 的应用数据、用户工作区和运行配置。桌面端可以把完整数据目录迁移到新的位置；迁移会在停止本地服务后复制完整状态、切换位置并重启应用。

迁移前应提醒用户：

- 选择稳定、空间足够并且自己有权限使用的磁盘位置。
- 迁移的是完整 Nexus 状态，不是只移动某个项目或某段聊天。
- 过程中不要强制退出应用或移除目标磁盘。

网页端不提供本机数据目录迁移。

## 默认权限

权限页设置“以后新建的智能体”默认使用哪种权限方式。修改它不会追溯改动已经存在的智能体。

已有智能体的权限从联系人 → 选择智能体 → 工具中调整；当前会话还可能有自己的临时选择。权限越宽，智能体能直接执行的操作越多，也更需要关注外部发送、文件修改、删除和付费操作。

## 个人账号

个人页会根据当前登录方式和账号权限显示可用项目，例如头像和资料、账号角色、使用量、访问令牌或密码。不是每种部署都会显示所有项目。

修改密码、令牌或登录信息可能使其他设备重新登录。不要在聊天回复中回显完整令牌或密码。

## 模型服务

模型服务页可以：

- 添加、启用、停用或删除模型服务。
- 填写服务地址和密钥，并测试连接。
- 同步服务提供的模型，或手动添加模型。
- 查看和调整模型的上下文长度、输出能力和支持的输入类型等信息。
- 设置默认聊天、视觉、图片或后台任务模型。
- 界面提供时，从 CC Switch 导入或同步配置。

有些服务格式可以保存和测试，但不一定能直接作为普通聊天运行环境。以界面显示的可用状态和提示为准，不要只因为“连接测试成功”就承诺所有会话都能使用。

修改或删除正在使用的模型服务会影响智能体和定时任务。执行前先检查依赖并说明影响。

## 管理后台

有管理权限的用户可以从“管理后台”维护用户、使用方案、共享模型服务和项目权限。普通用户可能看不到此入口。

这些改动可能影响其他用户，不应仅凭一句模糊要求批量修改或删除。先确认目标范围、受影响对象和恢复方式。

## 版本、更新和日志

桌面端会显示当前应用版本。发现可用更新时，左侧会出现更新入口。排查问题需要时，可以从应用提供的操作导出日志；日志可能包含文件路径和运行信息，分享前应检查敏感内容。

## 常见排查顺序

用户说“功能不能用”时，按下面顺序缩小范围：

1. 确认入口是否只在桌面端、特定权限或完成配置后出现。
2. 确认正确的智能体、房间和会话仍然有效。
3. 检查模型服务、连接器、消息通道或浏览器是否已连接。
4. 检查当前会话的模型和权限，而不只看全局默认值。
5. 查看界面上的失败提示、任务运行历史或连接状态。
6. 需要时导出诊断日志，但不要在普通回复里暴露内部 ID 和完整路径。

如果用户只是不会操作，优先从“指南中心”重新打开对应引导，不要先让用户看日志。
