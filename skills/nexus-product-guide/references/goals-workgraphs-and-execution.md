# Goal、工作图与复杂任务

## Goal 是什么

Goal 用来告诉智能体“最终要得到什么结果”。它适合不能靠一条回复完成、需要连续推进和检查完成情况的事情。

入口：聊天输入框中的 Goal 入口，或使用界面提供的“设定 Goal”。

设定后，Nexus 会把目标单独保存并开始继续推进，而不是把它只当成一条普通聊天消息。智能体完成工作后，还要根据当前目标和完成要求检查是否真的可以结束。

Goal 适合描述结果，例如“完成本周竞品报告并给出可核查的来源”。不要把每一步操作都塞进 Goal；步骤和分工更适合交给工作图。

## 工作图是什么

工作图把复杂任务拆成若干块，并显示：

- 哪些事情必须完成。
- 哪些可以同时进行，哪些要等前一步完成。
- 当前由谁负责。
- 每次尝试、结果、复核和最终交付。
- 工作过程中形成的文件或其他成果。

入口有三种：

1. 在输入框输入 `/workgraph`，为当前请求创建一张新的工作图。
2. 在聊天上方打开“工作图”，查看当前任务和历史记录。
3. 从左侧“工作图”打开保存过的模板，再复制命令、继续编辑或复用。

工作图页面主要用于查看真实进展，不提供随意拖动节点来改状态的按钮。需要调整任务内容或结构时，直接在聊天里告诉智能体想怎么改。

## 用对话编辑工作图

完成过的工作图可以整理成以后重复使用的模板：

1. 在已完成的工作图上选择“保存为草图”。
2. 填写名称、说明和以后使用的 `/命令`。
3. 如果需要调整，选择“调整”进入编辑页。
4. 左侧直接告诉 Nexus 想增加、删除、合并、拆分或改写哪些步骤。
5. 右侧会实时显示完整草图。
6. 选择满意的版本并应用，然后完成当前页面的保存或更新操作。

每次编辑都会形成一个可回看的版本。选择旧版本不会删除更新的版本；关闭编辑页也不会删除这段专用编辑对话，再次打开可以继续。

这段编辑对话只用于修改草图，不会改写原来的聊天记录或已经完成的工作图。保存时保留的是可复用的任务结构，不会把上一次的负责人、完成状态、输出文件和复核结论当成下一次的既定事实。

## 保存和复用工作图

入口：左侧“工作图”。这里可以按名称、命令或节点搜索，查看模板说明和结构，还可以：

- 复制对应的 `/命令`。
- 继续用自然语言编辑。
- 删除不再需要的模板。

每次运行保存过的 `/命令`，都会创建一张新的工作图和新的执行记录，不会继续旧任务。删除模板不会删除以前使用它形成的历史工作图。

普通单人聊天或多人房间里，也可以直接要求智能体查看、整理、修改或保存工作图。真正保存前需要用户明确确认。

## 临时子任务

智能体可以把当前任务中的一小块临时交出去，例如让另一个执行者查资料、检查代码或复核结果。这样的工作会出现在“临时子任务”页中。

临时子任务适合一次性的短分工；多人房间适合长期存在、用户可以持续交流的多位智能体。没有发生临时分工时，对应页面可能为空。

## 可视化结果

输入 `/visualize`，或直接要求“用可交互界面展示”，可以让智能体把适合的结果做成图表、对比工具、流程图或其他可操作的视觉内容。

可视化适合帮助理解关系和变化，不等于自动保存为工作图。工作图关注任务执行，可视化关注结果怎么展示。

## 怎么选择

| 用户想要的东西 | 选择 |
| --- | --- |
| 明确最终要完成的结果，并持续推进 | Goal |
| 拆分任务、安排先后关系和负责人 | 工作图 |
| 保存一套以后还能重复使用的任务结构 | 保存工作图模板 |
| 临时把一小块工作交出去 | 临时子任务 |
| 让多位长期智能体公开协作 | 多人房间 |
| 把结果展示得更容易理解和探索 | 可视化 |

这些功能可以组合使用。例如先设定 Goal，再由工作图管理分工，最后用可视化展示结果。
