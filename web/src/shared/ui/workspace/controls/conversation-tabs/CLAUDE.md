# conversation-tabs/ - Workspace 会话标签

- `conversation-tabs-model.ts` 定义排序、打开集合、活动标签、关闭邻居、稳定溢出判定和宽度分配等纯模型；打开集合按保留存活项、追加外部选中项、保证非空三阶段归约。溢出判定只依赖轨道宽度与标签最小可读宽度，不得读取宽度动画中的瞬时 DOM 溢出状态。
- `use-conversation-tabs-controller.ts` 只维护浏览器式标签事务和容器测量，不渲染样式。
- `use-conversation-tabs-scroll.ts` 维护标签带溢出测量、活动标签归位、宽度动画稳定后的二次边界校正、触控板滚动和鼠标拖拽。
- `conversation-tabs-scroll-rail.tsx` 只渲染溢出时可操作的滚动轨道；轨道默认保持视觉静默，鼠标进入标签带时以中性色浮现，只有实际按下拖动或键盘聚焦时才增强为强调色。
- `conversation-tabs-overview.tsx` 的纵览触发器只在真实溢出时作为图标胶囊的左分区出现；浮层沿用当前主题环境底色与半透明面板混合材质，不得退化为白色实体卡片。
- 标签轨道以 40px 高的透明、同背景低对比阴影框承托整排 36px Session 标签，上下各保留 2px 层级间距，不额外铺浅色填充；右侧图标胶囊同为 40px，活动 Session 标签使用透明底、边框和轻阴影建立层级，非活动标签只降低文字明度，蓝色仅保留在小圆点等状态标记。
- `workspace-conversation-tab-model.ts` 统一推导单标签的活动态样式、宽度、标题和关闭态。
- `workspace-conversation-tab.tsx` 只渲染单个标签；不得自行推导会话集合状态或状态样式。
- 当前活动标签必须属于打开集合，宽度模型不得依赖 Effect 的执行时序修正非法状态。
- 外部 Session 判断和标签统一来自 `lib/conversation/external-session.ts`，标签域不得维护通道别名。
- 默认打开集合保留全部最近会话，不得设置与实际可用空间无关的标签数量上限。标签共同占满可用轨道，每新增一个会话都按活动态权重平滑缩窄；达到可读最小宽度后，不再硬挤或移除旧标签，而是进入可由触控板、鼠标拖拽与滚动轨道直接浏览的横向溢出区。溢出宽度以活动标签为锚重新计算一屏可完整容纳的普通标签数量，滚动结束时吸附到标签边界，尽量避免可视区停在半个标签上。视觉遵循 Safari 标签栏：当前标签使用带轻阴影的浮起圆角底面，非当前标签保持透明并以细分隔线分段，关闭动作只在悬停或键盘聚焦时出现。创建入口固定在轨道右端，以无文字 `+` 图标呈现；会话总览只在标签真实溢出时出现，并作为同一椭圆胶囊的左分区与创建入口组合。滚动轨道同样只在真实溢出时出现。总览列出所有最近会话，选择被收纳的会话时须先把它加入打开集合。会话正文由上层仅挂载当前活动会话。
- 窄容器仍保留当前会话标题；创建入口始终保持纯图标，依靠可访问名称和悬停提示解释动作。
- 桌面标签轨道随共享顶栏使用 40px 轨道和 36px 标签/动作高度，避免超宽屏把顶栏压成细线；宽度分配仍只由容器模型决定。
