# conversation-tabs/ - Workspace 会话标签

- `conversation-tabs-model.ts` 定义创建时间排序、打开集合、活动标签、关闭邻居、稳定溢出判定和宽度分配等纯模型；标签按 `created_at` 从旧到新稳定排列，激活或消息活动不得重排，打开集合按保留存活项、追加外部选中项、保证非空三阶段归约。溢出判定只依赖轨道宽度与标签最小可读宽度，不得读取宽度动画中的瞬时 DOM 溢出状态。
- `use-conversation-tabs-controller.ts` 只维护浏览器式标签事务和容器测量，不渲染样式。
- `use-conversation-tabs-scroll.ts` 维护标签带溢出测量、活动标签归位、宽度动画稳定后的二次边界校正、触控板滚动和鼠标拖拽。
- `conversation-tabs-scroll-rail.tsx` 只渲染溢出时可操作的滚动轨道；轨道默认保持视觉静默，鼠标进入标签带时以中性色浮现，只有实际按下拖动或键盘聚焦时才增强为强调色。
- `conversation-tabs-overview.tsx` 的纵览触发器只在真实溢出时固定于 Session 托盘左端；创建入口固定于同一托盘右端，中间标签视口独立横向滚动，窄宽度下两端动作不得随标签移出可视区。纵览浮层使用主题高层表面与 popover 投影，托盘本身不得借用浮层阴影。
- Session 托盘是单一 40px 高、10px 圆角的中性浅灰细边框容器：左侧纵览、中央标签视口、右侧创建入口只用 1px 低对比 hairline 分区，不得再生成独立动作胶囊或阴影。中央承托整排 36px、8px 圆角 Session 标签，上下各保留 2px、左右各保留 5px；宽度分配、溢出判断和滚动归位必须共同扣除两端固定动作与中央内边距，保证首尾标签完整。活动 Session 标签使用白色或主题最高层底面与完整细边界，托盘和活动标签都不绘制外投影；非活动标签保持透明并使用清晰的次级文字，连续非活动标签之间绘制 16px 低对比竖线，当前标签两侧及悬停/聚焦标签两侧不得出现分隔线；焦点蓝只表达键盘焦点或信息状态。
- `workspace-conversation-tab-model.ts` 统一推导单标签的活动态样式、宽度、标题、关闭态和稳定状态类；当前标签显式绘制完整细边界，非当前标签保持透明并由 Chrome 式短分隔线组织远端标签。
- `workspace-conversation-tab.tsx` 只渲染单个标签；不得自行推导会话集合状态或状态样式。
- 当前活动标签必须属于打开集合，宽度模型不得依赖 Effect 的执行时序修正非法状态。
- 外部 Session 判断和标签统一来自 `lib/conversation/external-session.ts`，标签域不得维护通道别名。
- 默认打开集合保留全部最近会话，不得设置与实际可用空间无关的标签数量上限。标签共同占满可用轨道，每新增一个会话都按活动态权重平滑缩窄；达到可读最小宽度后，不再硬挤或移除旧标签，而是进入可由触控板、鼠标拖拽与滚动轨道直接浏览的横向溢出区。溢出宽度以活动标签为锚重新计算一屏可完整容纳的普通标签数量，滚动结束时吸附到标签边界，尽量避免可视区停在半个标签上。视觉遵循 Chrome 标签栏的无阴影层级：当前标签用最高层底色、完整细边和中等字重与浅灰轨道分离，非当前标签透明，只有连续非活动标签之间保留短竖线，关闭动作只在悬停或键盘聚焦时出现。创建入口固定在统一托盘右端，以无文字 `+` 图标呈现；会话总览只在标签真实溢出时出现并固定在统一托盘左端，二者与中央滚动标签带构成一个组件。滚动轨道同样只在真实溢出时出现。总览列出所有最近会话，选择被收纳的会话时须先把它加入打开集合。会话正文由上层仅挂载当前活动会话。
- 窄容器仍保留当前会话标题；创建入口始终保持纯图标，依靠可访问名称和悬停提示解释动作。
- 桌面标签轨道随共享顶栏使用 40px 轨道和 36px 标签/动作高度，避免超宽屏把顶栏压成细线；宽度分配仍只由容器模型决定。
