# Workspace Surface

- `workspace-surface-header.tsx` 只组合单行身份、导航和尾部插槽；不存在真实消费者的布局模式不得保留在公共契约中。
- Header 间距由共享样式统一表达两级节奏：身份、会话、工具和协作区之间使用稳定组距，组内动作使用紧凑控件距；完整胶囊与工具组之间只用留白分组，不叠加装饰分割线。View Tab、历史、Room 成员和溢出动作属于同一个分段工具胶囊，共享暖色轻底面、完整细边和软阴影，内部只绘制低对比分段线并由当前项在胶囊内提亮；Room 延续历史后接成员的操作顺序，成员不叠加独立底色，Session 纵览与新建保持另一组。业务 Header 不得额外包裹自定义 `gap` 改写节奏，桌面工具动作统一使用 36px 高度。
- 工作区视图标签遵循 Session 标签的状态层级：未选中透明、悬停轻微提亮，活动项复用同一个边框、底面和软阴影 recipe；形状遵循承载容器，Session 使用标签圆角，分段工具胶囊内的 View Tab、历史、成员与溢出入口统一使用扣除 inset 后的同心胶囊弧度。只有当前可关闭的视图显示 `×`，关闭按钮必须位于活动底面之上的独立点击层；Session 标签与承载整排标签的阴影托盘共享同一个圆角 token，托盘阴影必须沿圆角轮廓投射，左右端不得退化为矩形阴影。
- Header 身份头像的立体层级由外层基座统一提供：细描边、短接触阴影和柔和下投影；业务头像本身不叠加第二套阴影。
- Workspace Header 是壳层的轻抬升材质，不使用贯穿宽度的底边线；它与导航轨、目录栏共同消费主题壳层 token，通过同色系明暗和宽阴影与主画布交接，业务 Header 不得自行恢复硬分隔。
- Header 内容在完整 60px 材质层内居中；壳层已不再预留 1px 分隔线，业务组件不得通过偏移补偿重新制造上下留白差。
- 所有带标签的 Header 在窄容器中把次级视图收进带当前标签文字的菜单；Room 额外优先保留当前会话标题、创建入口和历史入口，不得退化为一排无语义图标。
- `workspace-surface-toolbar-action.tsx` 统一 Surface 工具栏动作外观，不依赖 Header 的布局实现。
- `workspace-header-layout.ts` 保存侧边栏与主内容区共用的 60px 桌面高度基线，布局双方不得复制数值；会话标签和动作随基线同步增高，不能只给外层追加空白。
- `workspace-surface-scaffold.tsx` 只提供 Header 与主画布骨架；业务滚动、状态和命令留在调用方。
- `workspace-surface-view.tsx` 用 `page`、`overlay` 与缺省无障碍标题表达三种真实模式；不得重新引入控制标题组合的布尔参数。
- 标题、标签和中部导航的可选组合在各自私有组件内收口，根 Header 不维护布尔状态矩阵。
