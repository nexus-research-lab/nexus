# 列表原语

- 本目录拥有通用列表行与行内动作的结构和样式。
- `list-row-model.ts` 统一投影活动态、交互语义和根样式；`list-row.tsx` 只组合默认内容与调用方插槽。侧栏消费者通过明确的 `activeTone="sidebar"` 选择共享侧栏状态，不在调用方覆盖默认活动类。
- 普通资源目录使用默认密度；会话切换器等单一选择面使用 `density="compact"`。消费者不得以私有 `min-height / padding / radius` 复制紧凑列表几何。
- 默认活动行与侧栏活动行都使用中性浅灰底面和强文字，不绘制边框、阴影、品牌色侧标或“当前”徽标。普通行保持透明且不绘制边界，hover 只增加更轻的中性底并提升文字；目录消费面可显式选择 `muted` 非活动文字层级，其他列表不得被连带降权。
- 默认双行标题与摘要总高必须落在 40px 身份头像边界内，不能让文字从头像上下两端溢出；需要更复杂内容的目录使用 `children` 明确自定义。
- 默认内容的标题固定使用 `sectionTitle`，摘要固定使用 `metadata`；业务调用方只传内容，不得通过 `text-* / font-* / leading-*` 改写默认排版。
- 列表资源、选择状态和命令生命周期由业务目录负责。
