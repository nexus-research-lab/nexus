# 导航原语

- 本目录拥有通用标签页结构及样式；`UiTabs` 使用纯文字优先的低对比中性选中态。
- `UiTabs` 把消费方提供的单项类名挂在稳定的包装节点上，响应式隐藏或收纳必须作用于该节点，不能留下空白 `gap`。
- `UiTabs` 为活动标签提供独立关闭按钮类名；只要标签组支持关闭，所有项目就必须预留相同关闭槽位，消费者可调整局部节奏，但不得因活动态出现或消失按钮而改变标签宽度。
- 可关闭标签统一通过 `getUiTabDismissClassName` 获得 24px 命中区、6px 圆角、危险态 hover 与键盘 focus；Session 和工作区 view 不得再复制两套关闭几何。
- 页面级栏目使用中灰文字与低对比轻底表达当前位置，不借用品牌蓝；未选中项只在 hover 时轻微提亮，不增加边框宽度、阴影或布局位移。
- 路由、页面状态和业务可见性由消费者投影后传入。
