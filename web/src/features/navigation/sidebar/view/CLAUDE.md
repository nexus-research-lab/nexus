# 宽侧栏视图

- 折叠栏和展开面板只表达布局差异，不读取路由、Store 或业务 API。
- 主 Tab、Nexus 入口和系统操作必须复用同一组件树。
- `sidebar-primary-tabs-model.ts` 通过 rail/panel 规则表统一主 Tab 的样式、可见标签和无障碍投影；TSX 只保留一套按钮结构。
- 主 Tab 的选中态复用设置导航的主题活动底面、细边界与软阴影，浅色主题采用低饱和暖象牙灰，品牌色只留在图标；不得再用大面积 primary 混色表达当前目录。
- 展开态 NEXUS 字标使用本地 Panchang 可变字重和克制的垂直明暗、下投影建立体积感，并与共享 60px 桌面顶栏基线垂直居中；不得改成高饱和发光标识。
- 展开态品牌栏的底部分隔线必须跨过侧栏右侧舞台留边，与工作区顶栏连续衔接；主体导航仍保留原有横向留白。
- 折叠栏和展开面板的系统操作分隔线必须同样跨过右侧舞台留边，与侧栏外边界相交，不得在设置入口上方留下短横线或断口。
- 消费接口由视图定义并保持窄小；新增状态先进入上层控制器投影。
