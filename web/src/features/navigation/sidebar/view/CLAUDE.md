# 宽侧栏视图

- `sidebar-panel.tsx` 是桌面侧栏唯一壳层，只表达宽度、目录可见性与底部动作位置，不读取路由、Store 或业务 API；不得恢复折叠/展开两套根组件。
- Nexus 主智能体只作为聊天目录顶部的默认 DM，不在本目录维护第二套入口或激活状态。
- `sidebar-primary-tabs-model.ts` 维护主 Tab 的唯一 Dock 几何；展开与收起始终复用同一套 32×32px 图标交互面、18px 图标、短标签和无障碍投影，TSX 只保留一套按钮结构。
- `sidebar-pinned-conversations.tsx` 只渲染上层已解析的固定会话，`sidebar-pinned-conversations-model.ts` 只按指针与目标项几何判断插入前/后；固定区仅在有内容时显示能力入口下方的短分割线，并独立纵向滚动以保持一级导航与底部操作可见。固定项整体允许原生拖放：目标上/下半区分别表达插入前/后，落点用短主色线反馈，靠近滚动区边缘时继续滚动，完成后只向上提交排序。图标与标题对齐 64px Dock 水平中心轴，选中与 hover 只使用和一级导航一致的 32px 图标框，标题仅切换文字强调；取消固定 X 位于右上外沿且不得遮挡图标，并保持至少 24px 点击热区，不得关闭或删除会话。
- 主 Tab 的选中态与聊天、联系人和能力目录复用共享中性灰底面，并比短暂 hover 深一档以支持持续定位；不绘制独立边框或浮起阴影，品牌色只留在精确状态信号，不得再用大面积 primary 混色表达当前目录。
- 展开态顶部只保留链接 Launcher 的 NEXUS 字标与右侧折叠控制；字标链接的命中区只包裹可见字标，中间真实空白留给桌面窗口拖动。macOS 系统保留宽度已经包含 traffic lights 后的呼吸区，品牌栏不得再叠加左 padding，字标与收起动作两侧保持均衡。有效退出与设置、引导共用底部操作区，并在展开态固定于右侧。退出仅由上层投影真实密码认证会话，Agent 头像不得重新塞回品牌栏。字标使用本地 Panchang 可变字重和克制的垂直明暗、下投影建立体积感，并在浏览器 60px、macOS 原生红灯 Y 中心推导出的共享顶栏内保持上下视觉等距；不得改成高饱和发光标识。
- 68px 折叠态由 4px 宿主对齐留白和 64px Dock 组成；一级导航、固定会话与底部动作全部对齐 Dock 的水平中心轴，固定项 X 单独贴近卡片右上外沿。品牌随壳层裁切淡出，Web 折叠控制与 Dock 共用 Header 垂直中心轴，macOS 控制则沿右缘滑到 traffic lights 右侧，中段主 Tab 不缩放、不换位，底部设置、引导与有效退出沿布局曲线进入单列。
- 展开态品牌栏的底部分隔线必须跨过侧栏右侧舞台留边并止于唯一外缘 hairline，主工作区顶栏不得续画横线；主体导航仍保留原有横向留白。
- 底部操作分隔线必须跨过右侧舞台留边并与侧栏外边界相交；Footer 保持同一 DOM，通过高度和动作坐标过渡完成横排/单列切换，不得在设置入口上方留下短横线、断口或瞬时重排。
- 与主画布相邻的桌面侧栏通过 `data-shell-split-edge` 绘制唯一外缘 hairline；该线必须越过桌面顶部 inset、覆盖 Header/Footer 但不拦截 resize 热区，移动端全宽目录不得绘制。
- 消费接口由视图定义并保持窄小；新增状态先进入上层控制器投影。
- `use-sidebar-update-version.ts` 只在桌面运行时且桥接可用时读取宿主持久化的可用版本，Web 环境不得渲染更新入口；`sidebar-update-indicator.tsx` 通过 `app.start_update` 直接启动原生下载、校验与安装链路，不得退回普通 Release 外链；`sidebar-utility-actions.tsx` 将存在的更新提示作为底部操作参与展开/折叠布局，展开时固定在右下角。
