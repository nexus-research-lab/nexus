# 宽侧栏视图

- 折叠栏和展开面板只表达布局差异，不读取路由、Store 或业务 API。
- Nexus 主智能体只作为聊天目录顶部的默认 DM，不在本目录维护第二套入口或激活状态。
- `sidebar-primary-tabs-model.ts` 通过 dock/rail 规则表统一主 Tab 的样式、可见标签和无障碍投影；TSX 只保留一套按钮结构。
- 主 Tab 的选中态与聊天、联系人和能力目录复用共享中性浅灰底面，不绘制独立边框或浮起阴影，品牌色只留在图标；不得再用大面积 primary 混色表达当前目录。
- 展开态顶部只保留链接 Launcher 的 NEXUS 字标，以及右侧有效退出与折叠控制；退出仅由上层投影真实密码认证会话，Agent 头像不得重新塞回品牌栏。字标使用本地 Panchang 可变字重和克制的垂直明暗、下投影建立体积感，并与共享 60px 桌面顶栏基线垂直居中；不得改成高饱和发光标识。
- 56px 折叠态顶部只显示垂直居中的展开按钮，不显示 `N` 字标或退出；中段依次放聊天、联系人和能力，底部只放设置与引导。
- 展开态品牌栏的底部分隔线必须跨过侧栏右侧舞台留边并止于唯一外缘 hairline，主工作区顶栏不得续画横线；主体导航仍保留原有横向留白。
- 折叠栏和展开面板的底部操作分隔线必须同样跨过右侧舞台留边，与侧栏外边界相交，不得在设置入口上方留下短横线或断口。
- 与主画布相邻的桌面侧栏通过 `data-shell-split-edge` 绘制唯一外缘 hairline；该线必须越过桌面顶部 inset、覆盖 Header/Footer 但不拦截 resize 热区，移动端全宽目录不得绘制。
- 消费接口由视图定义并保持窄小；新增状态先进入上层控制器投影。
