# 宽侧栏视图

- `sidebar-panel.tsx` 是桌面侧栏唯一壳层，只表达宽度、目录可见性与底部动作位置，不读取路由、Store 或业务 API；不得恢复折叠/展开两套根组件。
- Nexus 主智能体只作为聊天目录顶部的默认 DM，不在本目录维护第二套入口或激活状态。
- `sidebar-rail-action.tsx` 是一级入口与固定会话共用的唯一 Dock 动作所有者，复用同一套图标框、标签、选中/hover/focus 状态和无障碍投影。一级动作占满轨道可用宽度以保留完整中英文标签，尺寸真相见 `design.md`；路由与计数只由上层 model 派生，不得再建立返回 className 的展示 model。
- `sidebar-pinned-conversations.tsx` 只渲染上层已解析的固定会话，`sidebar-pinned-conversations-model.ts` 只按指针与目标项几何判断插入前/后；固定区仅在有内容且侧栏展开时显示能力入口下方的短分割线，并独立纵向滚动以保持一级导航与底部操作可见。固定项整体允许原生拖放：目标上/下半区分别表达插入前/后，落点用短主色线反馈，靠近滚动区边缘时继续滚动，完成后只向上提交排序。固定项居中于同一轨道，选中与 hover 只使用和一级导航一致的图标框，标题仅切换文字强调；取消固定 X 位于右上外沿且不得遮挡图标，并保持至少 24px 点击热区，不得关闭或删除会话。
- 主 Tab 的选中态与聊天、联系人和能力目录复用共享中性灰底面，并比短暂 hover 深一档以支持持续定位；不绘制独立边框或浮起阴影，品牌色只留在精确状态信号，不得再用大面积 primary 混色表达当前目录。
- 展开态顶部只保留链接 Launcher 的仅首字母大写的 Nexus 字标与右侧折叠控制；`sidebar-brand-link.tsx` 独占纯色文字字标，视觉规则见 `design.md`。字标使用本地 Panchang 字体，18px、280 字重与 0.18em 舒展字距，不再逐字平铺或叠加渐变阴影，由外层 Link 提供唯一可访问名称。链接占满可用宽度，字标靠左保持自然宽度；与收起动作之间保留 16px 空白用于桌面窗口拖动。macOS 系统保留宽度已经包含 traffic lights 后的呼吸区，品牌栏不得再叠加左 padding，字标与收起动作两侧保持均衡，并在共享顶栏中保持上下视觉等距。Desktop 可选远程登录与有效退出收进底部账号菜单，设置图标固定于右侧，引导收进账号菜单。退出仅由上层投影真实密码认证会话，Agent 头像不得重新塞回品牌栏。
- 折叠态将整个侧栏壳层收至 0 宽并设为 inert；Web 只在工作区左上保留展开控制，macOS 展开控制位于 traffic lights 右侧。共享 Surface Header 只预留恢复触点结束到内容起点之间的标准间距，不得形成独立空栏；管理型 Content Header 可保留完整安全区。导航、目录、Footer 和外缘 hairline 都不得继续占位或参与键盘导航。
- 展开态品牌栏的底部分隔线必须跨过侧栏右侧舞台留边并止于唯一外缘 hairline，主工作区顶栏不得续画横线；主体导航仍保留原有横向留白。
- 展开态底部操作分隔线必须跨过右侧舞台留边并与侧栏外边界相交；收起态不渲染 Footer，也不得留下分隔线或占位。
- 与主画布相邻且处于展开态的桌面侧栏通过 `data-shell-split-edge` 绘制唯一外缘 hairline；该线必须越过桌面顶部 inset、覆盖 Header/Footer 但不拦截 resize 热区，折叠态与移动端全宽目录不得绘制。
- 消费接口由视图定义并保持窄小；新增状态先进入上层控制器投影。
- `use-sidebar-update-version.ts` 只在桌面运行时且桥接可用时读取宿主持久化的可用版本，Web 环境不得渲染更新入口；`sidebar-update-indicator.tsx` 通过 `app.start_update` 直接启动原生下载、校验与安装链路，不得退回普通 Release 外链；`sidebar-utility-actions.tsx` 仅承载展开态底部操作，更新提示固定在右下角，收起态不渲染 Footer。
- 桌面更新启动状态复用共享 Spinner 动效并保持侧栏既有 18px 图标几何；视图不得自行维护旋转或 reduced-motion class。

- 底部左侧账号入口占满设置按钮之前的剩余宽度，头像与常规字重的用户名靠左，长名称省略并保留完整共享 Tooltip，整条区域可点击并向上展开账号名称与统一引导菜单；仅有效密码认证会话显示退出。右侧保留设置和桌面更新提示，不再提供独立帮助按钮。账号资料与退出可见性由 controller 投影，菜单复用 UiActionMenu，头像复用 UiAgentAvatar。

底部操作栏固定为 48px，不再继承顶部原生窗口控制所需的 Header 高度；进入设置路由时隐藏，返回工作台后恢复。

账号菜单使用可点击进入个人设置的头像/名称首项，分隔线只分开身份与引导/退出动作；菜单使用公共浮层定位与视口约束，不测量或继承底栏宽度，账号名使用常规字重。

- 更新版本提示每次只允许一个桥接读取在途；慢响应时跳过本次轮询，失败保留最后成功版本，卸载清理定时器并丢弃迟到结果。原生宿主继续负责更新执行与错误反馈。

账号名称截断时保留完整共享 Tooltip；实际引导锚点只绑定账号按钮，内部 UtilityButton 不暴露未消费的锚点透传参数。

- Dock 标签截断时由共享 SidebarRailAction 保留完整共享 Tooltip，固定会话可覆盖为包含拖动说明的标题。
