# Skill 共享目录卡

- `skill-directory-card.tsx` 只统一能力页已安装、更新和社区 Skill 的卡片几何、数学曲线身份、点击层和内容层级。
- 标题、说明、徽标、元数据、动作可用性与命令仍由所属 `catalog/` 或 `external/` 域投影；只有影响当前决策的信息才能进入卡片。
- 整卡详情动作使用独立覆盖按钮；右上角领域动作必须保留自己的按钮语义，不得嵌套交互元素。
- 首行头像、标题与领域动作共用 40px 垂直中心轴，标题不得通过私有顶部偏移修正基线。
- 卡片保持桌面三列、窄窗逐级收拢；说明最多两行，用于支持启用或导入决策。已安装目录不显示重复状态、来源、作用域、标签和启用位置；更新与社区结果可保留版本、来源或导入状态等决策信息。
