# Pairings

- `pairing-model.ts` 负责完整配对集合上的筛选、统计、分组、展示文本和创建载荷。
- 分组名称优先当前 Agent 目录的非空姓名，再使用配对快照中的姓名；两者缺失时复用共享名称通称，不拼接 Agent ID。controller 按目录和当前语言重新分组，精确筛选、更新载荷和外部对象标识保持原值；此规则不代替 Agent 选择器的可辨识候选设计。
- `use-pairings-controller.ts` 一次加载完整配对集合，状态、渠道、智能体和搜索筛选均由本地派生；写命令成功后重新同步完整集合。
- `pairing-filter-bar.tsx` 负责状态视图和必要筛选，状态数量必须基于忽略当前状态的同一筛选范围计算。
- `pairing-list.tsx` 优先展示未授权请求，其余配对按智能体分组；绑定键、Session 等内部字段只放在共享 `UiDisclosure` 承载的技术详情中。
- 配对卡片顶部显示身份与授权操作，中间将处理智能体和会话目标以共享小号控件等宽对齐；默认显示可读名称、状态、频道/会话类型与外部对象标识；时间收进技术详情；外部对象是配对的管理身份，绑定键与 Session 才留在技术详情。待处理和 Agent 分组保留数量，用于快速判断授权规模。
- 配对分组标题复用 `CapabilitySectionHeader`，每个对象表面复用 `UiPanel`，标题、摘要、技术标签与标识分别选择共享 Typography 的 control、metadata、caption 与 code 角色；不得在列表中恢复私有字号、字重、等宽组合或任意圆角。
- 更新载荷直接使用 `UpdatePairingPayload`，禁止引入 `agentId` 等协议别名。
- 同一时间只执行一个配对写命令，重复点击由 ref 同步拦截。
- 创建、更新、删除结果未知时保留 exact 配对意图，只用 owner 全量配对读模型核对目标状态；列表仍是旧状态不能证明写入未发生，也不能自动重放。当前页面在核对或用户明确开始新操作前保持写锁。
- 手动创建弹窗直接显示失败闭环；后台反馈不得被弹窗遮住。Session 标识只进入用户主动复制，不回显在成功或失败文案中。
- 手动创建弹窗使用 plain chrome；首屏只展示渠道、会话类型、外部对象、显示名称与处理 Agent，通道账号、Thread 和初始状态进入共享 `UiDisclosure` 的 section 高级区，不在标题和尾部提示重复解释匹配协议。
- 创建等待态使用共享 `md` Spinner；弹窗不得自行拼接尺寸、旋转或 reduced-motion class。
- 创建字段的可见标签与输入/选择 trigger 用明确 ID 配对，账号说明由公共 Field 关联；字段 ID 不参与配对路由、载荷或持久身份。
- 创建、列表改绑和 Agent 筛选共用 `lib/agent-selection-options.ts`；列表只生成一次完整目录选项再交给行视图。目录缺项保留原选择为禁用显示项，不自动换成其他 Agent；创建只允许当前目录中确实存在的所选 Agent 提交。初始未选择且目录后到时仍可选择首项，已有草稿选择消失则必须等待恢复或由用户明确重选。弹窗标题和外部对象字段也必须使用实例级 useId，不能保留固定 DOM ID。

创建请求进行中，所有关闭入口（包含 Escape/遮罩/标题按钮）和草稿字段一并锁定，读取失败或创建未完成后仍保留原草稿；禁写恢复态沿用已有反馈动作。创建弹窗、目录、列表与筛选标签均由中英文 capability 目录提供；渠道/会话/状态的单一键表生成当前语言选项，协议枚举始终保持不变。语言切换不能重建创建草稿，时间按当前语言格式化；当前语言的可见渠道/会话/回退名称同时参与列表搜索与忽略状态的数量计算，既有中文搜索标签和协议渠道值保留为兼容搜索值。

- `pairing-session-target.tsx` 编辑独立 IM 或本地 Room 的精确话题，沿用配对 Agent；读取失败保留草稿并阻止提交，写入携带 `binding_version`。更换 Agent 清空 Room 目标，须重新选择；`pairing-recovery.ts` 按目标与版本核验未知写结果。

- `browser-tests/pairings.spec.ts` 用隔离 App 数据检查配置控件等宽、同高、对齐、窄屏无溢出与详情折叠。

- 会话目标参考定时任务的双栏选择：左侧群聊、右侧具体会话，支持搜索；独立聊天与群聊在左栏并列；底部选择摘要与取消、保存同排。草稿显示完整路径，显式保存才写入，目录失败禁止提交。

- 会话选择器复用定时任务的 form-picker 锚定浮层，固定高度与内部双栏滚动；打开、加载及选群不改变卡片几何，Escape/外点取消并返回焦点。

- 候选包含当前处理智能体的本地 DM 与开启私域消息的群聊，DM 不要求群聊私域开关；绑定沿用精确 room_id/conversation_id。更换 Agent 通过既有版本 key 重建选择器。
