# Channel Catalog

- `channel-catalog-model.ts` 负责排序、搜索，以及卡片动作、徽标、元数据和统计项的完整投影；频道数量少，不提供状态下拉，未接入的频道不写“未绑定”元数据。
- `use-channels-controller.ts` 持有频道、Agent、选中项和目录反馈。
- 选中项由 `channel_type` 从最新列表派生，不复制完整频道对象。
- 卡片视图只消费判别式动作和可直接渲染的条目，不得重新解释协议状态；一行平台用途参与搜索也直接展示，API/长连接实现文案不进入目录。
- 卡片标题、说明、元数据使用共享 Typography；卡片只保留配置入口，平台接入文档链接放在连接弹窗的“连接说明”里；不得导入内部样式函数后手写原生 DOM。
