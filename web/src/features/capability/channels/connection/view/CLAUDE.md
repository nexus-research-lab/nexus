# Channel Connection View

- `channel-connect-dialog.tsx` 只负责编排弹窗、表单提交和删除确认。
- 字段区与 Footer 各自定义所需的窄控制器接口，不依赖生产者的完整返回类型。
- 凭证字段与处理 Agent 的可见标签关联到公共控件；DOM ID 按视图实例生成，保留现有字段 name、自动填充、secret 保留和校验规则。
- 展示文案与状态标签归纯模型，视图不得复制状态判断顺序。

- 表单/底部动作和删除确认的短文案从当前双语目录生成；切换语言不改变草稿、协议值或动作优先级。弹窗标题使用实例 useId，避免重复弹窗的 ARIA ID 冲突。
