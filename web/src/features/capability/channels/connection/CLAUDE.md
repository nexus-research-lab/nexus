# Channel Connection

- 主控制器只持有频道配置草稿、当前服务端快照和删除确认状态。
- `login/` 独占扫码会话、状态投影、轮询和验证码视图。
- `view/` 独占字段表单、Footer 与确认文案投影，各视图自行定义窄控制器接口。
- 保存、验证码、断开频道和删除账号复用主控制器提供的唯一命令互斥入口。
- 保存配置、断开频道和删除账号的未知结果绑定 exact Channel/account 意图；只通过 Channel 目录核对，无法证明时禁止重复写，弹窗也不能在保护未解除时直接关闭。
- 配置保存与启动扫码是两个独立阶段：配置 ACK 后启动扫码失败不得回退成“配置保存失败”；恢复扫码只复用服务端同配置版本的活动会话，不再次保存配置。
- 已连接账号默认显示用户标识或账号标识、状态、更新时间和当前错误；这些字段用于区分与修复被管理对象，不得误当作可隐藏的协议诊断。
- 账号与登录分区只通过 `UiPanel` 选择表面和圆角，通过共享 Typography 选择标题、元数据、错误说明与技术标识；删除、断开等瞬时加载图标复用全局 Spinner recipe，不在频道视图内重建视觉常量。
- Channel 与账号运行错误只把 `connection_state`/`last_error` 当作异常事实，展示产品化的问题、影响与恢复动作，不展示 `last_error` 原文；断开 Channel 会删除其配置、账号和配对，删除账号会删除该账号配对，确认文案必须与事务语义一致。
- 外部文档和 Discord 授权使用带 `noopener noreferrer` 的浏览器原生链接，不通过脚本弹窗伪造可确认的打开结果。
- 弹窗壳层只编排视图和提交事件，不直接编排 API 请求。
- 连接弹窗使用 plain chrome；平台准备步骤默认折叠为“连接说明”，字段和当前连接动作优先进入首屏，必要教程保留但不作为视觉主角。
