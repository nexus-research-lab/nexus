# 定时任务看板

- `scheduled-task-board.tsx` 只处理加载、错误、建议空态和四组状态装配。
- `scheduled-task-card.tsx` 负责单项必要信息与操作菜单，不请求 API，也不解释运行协议；标题、指令和错误摘要各自最多占一行。
- `scheduled-task-board-model.ts` 是状态分列、排序、卡片文案和建议预设的单一真相源。
- 看板状态由任务事实自动投影，不提供拖拽或人工状态迁移；历史执行结果不伪装成独立工作流阶段。
- 看板与能力标题一起铺满可用工作面，始终保持四列状态关系；宽度不足时由看板容器横向滚动，各列任务区独立纵向滚动，不折成两列。
- 无任务时的快速建议复用普通管理目录的桌面三列网格，不影响正式看板的四列结构。
- 卡片只显示任务名称、指令、计划、当前时间状态和失败摘要；执行会话、投递目标等高级字段留在编辑与历史视图。
