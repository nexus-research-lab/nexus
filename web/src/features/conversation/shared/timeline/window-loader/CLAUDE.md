# 连续窗口加载

- `continuous-window-model.ts`: 根据视口与驻留窗口两端的距离决定向哪一端扩展（older / newer / latest），并给出相反端的淘汰方向与无进展冷却；纯函数，不读 DOM。
- `use-continuous-window-loader.ts`: 只编排 RAF、滚动事件、会话代次和单飞请求；bottom 事务活跃时推迟检查，FOLLOW 中永不淘汰最新端。

浏览器驻留的是一段连续 round 窗口，外加实时/乐观尾部；窗口与最新内容之间至多存在一个 gap（`history_gap_after_round_id`）。Feed 不为未驻留的索引 round 渲染占位节点，窗口只在两端按阅读方向扩展，并从相反端按完整 round 淘汰。
窗口加载与导航跳转保持不同策略：窗口加载按视口到窗口边界的距离扩展，跳转加载以目标 round 为中心替换不相交的窗口；不得抽成丢失业务语义的通用队列。
被淘汰的 round 只要重新靠近窗口边界就再次具备加载资格；向前分页游标失效（淘汰或跳转后不再指向驻留头部）时按驻留头部的 round identity 重新请求，会话起点仍驻留时不再发起向前请求。
加载完成必须先通过会话代次校验；无进展或失败只进入短冷却，不得在当前会话内永久关闭某一端。
