# 可见窗口加载

- `visible-round-candidate.ts`: 从未加载占位元素中按滚动方向和焦点距离选择下一候选。
- `window-loader-runtime.ts`: 维护会话代次、在途请求、可失效完成集合、有限重试账本、滚动方向和顶部下拉重试意图。
- `use-visible-window-loader.ts`: 只编排 RAF、退避定时器、滚动事件和异步加载阶段。
- `visible-window-revision.ts`: 把浏览器内实际驻留的 round identity 纳入内容代次；等量窗口替换也必须使旧完成结论失效。

窗口加载与导航跳转保持不同策略：窗口加载选择视口候选并有限重试，跳转加载服务明确的最新目标；不得抽成丢失业务语义的通用队列。
加载结果使用 `loaded/missing/failed` 判别联合，结果必须先通过请求代次校验，再写入完成集合、重试账本或日志。
消息窗口淘汰已加载 round 后，该 round 必须重新具备加载资格；用户在顶部再次向下拉或向上滚轮属于新的显式读取意图，可以重开已耗尽的有限自动重试，但不能并发启动第二个请求。
