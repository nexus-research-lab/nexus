# 消息共享 UI

- `message-avatar.tsx` 提供跨消息、Thread 与状态卡复用的身份头像、可选联络动作和内容 / 控件两档圆角语义。
- `message-action-button.tsx` 提供消息头部复用的紧凑动作按钮与显式语气。
- `message-rail.tsx` 负责详情布局和约十条活动高度的滚动窗口，并消费时间线共享滚动模型判定虚化方向；流式详情可跟随新增内容，用户上滑后暂停、回到底部后恢复。详情窗口嵌套时通过共享上下文只让最外层拥有滚动、虚化和流式跟随，子详情直接参与外层内容流；展开的子详情标题随外层滚动吸顶，独立详情不受影响。
- `activity-icon.tsx` 统一工具动作图标，并为默认收起的连续活动组展示最近六个图标与溢出计数。

共享 UI 必须有多个真实消费者；消息项私有状态展示和外壳留在 `item/`，禁止重新建立聚合导出文件。
