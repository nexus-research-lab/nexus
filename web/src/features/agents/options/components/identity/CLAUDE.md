# identity/ - Agent 身份视图

- agent-profile-file-editor.tsx 只承载普通 Agent 根级 AGENTS.md 的完整 Markdown 预览、编辑和确认保存，不增加二次展开门槛；主 Nexus 没有该文件，身份页不渲染此编辑器，不复用工作区文件头部或文件保存工具栏。

- `agent-options-identity-tab.tsx` 只按布局描述组合资料、标签、模型和简介字段，不维护子域状态；创建来源显示可编辑的 AGENTS.md 行为模板，既有 Agent 仍由专用文件编辑器承载模板。
- `identity-profile-fields.tsx` 负责组合头像、名称与本地格式错误反馈，并用有序纯规则投影提示语义和色调；名称只是展示信息且允许重复，不显示“名称可用”成功态。同时声明模态编辑的初始焦点目标。没有错误时不得保留校验占位高度。
- `identity-avatar-picker.tsx` 以克制的当前头像和明确的“更换头像”中性文字动作作为唯一入口；内联形态让头像与动作共用正文左缘，弹窗形态维持居中。点击后通过共享锚定浮层展示五列大图标网格；身份表单不得恢复横向拖拽、翻页按钮、蓝色 pill 或常驻头像长列表，也不得只靠无文字的小图标暗示入口。
- `identity-vibe-tags.tsx` 独占待添加标签草稿并绑定编辑作用域，父级只持有已确认标签集合；新增输入固定在已确认标签之前，输入与添加按钮在内联详情中与名称字段同高并填满可用列宽；已确认标签使用固定单行高度的中性 chip 轨道，空态与有值时几何一致，溢出只在轨道内部横向滚动，不得推动模型区位移。
- `identity-model-selector.tsx` 统一 Provider/模型选项投影及选择值编解码。
- `identity-layout.ts` 用完整描述表维护 dialog/inline 布局差异，并集中投影名称、标签与模型的字段标签样式，子组件不得各自复制 label 配方；两种变体在窄屏都按资料、标签、模型自然堆叠，桌面统一使用“资料 + 标签 / 横跨整行的模型”两行网格，避免模型只占右半列留下无语义空白带；字段高度和分组间距需维持可触控性，不得为手机或窄平板复制整套 JSX。
