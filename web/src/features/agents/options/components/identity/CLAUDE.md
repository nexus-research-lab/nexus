# identity/ - Agent 身份视图

- agent-profile-file-editor.tsx 只承载普通 Agent 根级 AGENTS.md 的完整 Markdown 预览、编辑和确认保存，不增加二次展开门槛；主 Nexus 没有该文件，身份页不渲染此编辑器，不复用工作区文件头部或文件保存工具栏。

- `agent-options-identity-tab.tsx` 只按布局描述组合资料、业务标签、风格标签、模型和简介字段，不维护子域状态；业务标签仅用于管理目录分类，风格标签才进入运行时画像，两者不得互相投影。创建来源显示可编辑的 AGENTS.md 行为模板，既有 Agent 仍由专用文件编辑器承载模板。
- `identity-profile-fields.tsx` 负责组合头像、名称与本地格式反馈；名称、必填、校验状态与错误使用同一个实例级 `UiField` 关联，不另建颜色规则表。正在校验时隐藏旧错误；名称允许重复，不显示“名称可用”成功态。模态编辑的初始焦点继续落在名称输入，没有反馈时不保留占位。
- `identity-avatar-picker.tsx` 以克制的当前头像和明确的“更换头像”中性文字动作作为唯一入口；内联形态让头像与动作共用正文左缘，弹窗形态维持居中。点击后通过共享锚定浮层展示五列大图标网格；身份表单不得恢复横向拖拽、翻页按钮、蓝色 pill 或常驻头像长列表，也不得只靠无文字的小图标暗示入口。
- `identity-tags.tsx` 为业务标签与风格标签分别独占待添加草稿并绑定不同编辑作用域，父级只持有已确认标签集合。它是当前唯一 Tag 复合字段 owner，保留内部无壳原生输入，外层直接复用 `UiField`、`dialog-input`、Typography、Chip 和 Button；不为单一消费者新增通用状态抽象。已确认标签只在控件内部横向滚动，不推动模型区位移；原生 IME 回车通过共享识别器跳过，添加/移除后归还输入焦点，空白和重复值的添加按钮禁用，Enter 继续清理重复草稿。移除名称必须本地化。
- `identity-model-selector.tsx` 统一 Provider/模型选项投影及选择值编解码；使用实例级 Field 与公共 `UiSelectMenu allowLabelWrap`，不在业务层覆盖控件高度、内边距和错误关联。主 Agent 锁定、临时不可用选择、显式恢复默认与读取失败语义保持独立。
- `identity-layout.ts` 只维护 dialog/inline 的结构与断点差异，所有字段标签归 `UiField`。资料、标签与模型保持单一阅读顺序，空间足够时仅把业务标签与风格标签组成等宽双列；不得为手机或窄平板复制整套 JSX。创建模板与兼容编辑描述也使用实例级 Field，模板正文保持 code 角色，加载时只禁用对应字段。
