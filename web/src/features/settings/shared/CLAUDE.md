# shared/ - 设置与运营共享 UI

- `settings-panel-ui.tsx` 保存设置型表面的布局常量、语义文字和目录导航 Pattern；侧栏只传活动态、尺寸与内容，不得重写按钮字体、圆角、hover 或选中底色。窄屏仍保留会解释选项后果的行级说明，不得以统一隐藏的方式收缩。
- General、Operations 等消费者可依赖这里；共享层不得反向依赖具体设置子域。
- 普通设置选择器直接选择公共 `UiSelectMenu` 的紧凑尺寸；本层不保存触发器高度、字体、背景或焦点覆盖常量。设置标签、说明与分组文字遵循根目录设计规范，布局常量只决定设置行的列宽和内容节奏。
