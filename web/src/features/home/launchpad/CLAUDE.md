# Home Launchpad

## 职责边界

- `home-launch-model.ts`：纯投影。时段划分、进行中会话（只取等你回复与执行中的，排除主智能体与空闲会话，最多四条）、接下来的定时任务、新手提示词分类（四个分类各四条，外加从各分类随机抽一条的「随便看看」）与示例显隐阈值。
- `use-home-launch-controller.ts`：读取 Home 共享目录、Room 活动快照和定时任务目录；提交时通过 Direct Room 的 `initial` 草稿协议进入主智能体 DM，由该 Composer 投递到 inbox，首页不自行发送消息。
- `home-launchpad.tsx`：直接复用共享 `ComposerPanel`（草稿作用域 `home:main-agent`），以及字标下方以输入壳左边缘为基线的窄列：左对齐的问候、输入框、紧随其后的新手提示词选择器（一排居中的分类胶囊，点开后整排换成该分类的提示词列表，悬停在输入框占位处预览全文，点击填入，Esc 或 X 收起）、「接下来」定时任务条与无边框的「正在进行」会话行（每行只有头像和最新一句，状态色点压在头像右上角，名称放在悬停提示与读屏标签里）。不重复侧栏已有的会话列表与导航入口；首页输入框聚焦时不显示品牌蓝描边。Footer 的权限、模型与连接器绑定主智能体已有 Session；附件上传到主智能体工作区后经 `composer-initial-attachments.ts` 随 initial 草稿交接；Slash、队列与 Goal 依赖会话实时通道，首页不提供。

## 约定

- 提示词通过 Composer 草稿 Store 写入首页作用域，只填入不发送；悬停预览只改占位文字，不改动用户已输入的草稿。
- 定时任务读取失败只隐藏其中的任务行，不影响输入与进行中的会话。
