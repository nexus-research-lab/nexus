# Contacts 路由协调

- URL 查询参数是当前详情 Agent 的唯一选择状态，不维护镜像 state。
- 联系人侧栏行与管理目录卡片都通过同一个 `agent` 查询参数进入详情，禁止为目录卡片维护单独的既有 Agent 编辑弹窗。
- 详情页的桌面返回动作必须清理 `agent` 查询参数并回到联系人根目录；手机复用应用级返回栏，不在业务 Header 重复渲染。
- `view=create` 是从全局联系人侧栏进入共享创建编辑器的短生命周期路由意图；小屏在编辑期间保持联系人内容层，关闭编辑器后清理该意图并返回联系人目录。
- DM 导航复用 direct-room target，页面不得重复 ensure + route 拼装协议。
- 路由协调器只消费具体命令结果，不持有编辑器或确认弹窗状态。
