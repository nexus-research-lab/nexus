# Contacts 控制器

- 联系人集合只包含可管理的非主 Agent，编辑和删除命令不得再次判断另一套成员规则。
- 创建与更新复用 Agent Options 的字段投影和 mutation 参数。
- 创建控制器只生成 Agent Options Dialog 的关闭/创建判别状态；Agent store 为请求生成 owner-scoped 业务 ID，并可尽力保存以便重载后查询 exact receipt。本地存储失败不阻止创建，既有 Agent 的更新由详情页内联编辑器处理。
- 删除命令返回具体 Agent ID，是否离开当前路由由页面协调器决定；提交失败必须按领域 effect 区分未应用、已提交和结果未知，结果未知或已提交时先刷新权威目录，不得直接重放 DELETE。
- `use-agent-communication.ts` 绑定详情 Agent id，只加载好友、打开或恢复已有联系人通道、切换私信 Session、按稳定消息游标前插历史、订阅当前隐藏 Room 并以选中 Agent 身份发送；断线期间停止后台请求，连接建立或重连后补拉一次，无通道时保留 Composer，由首条发送原子创建 Room，删除只移除好友关系，旧作用域响应不得写回新 Agent 或新联系人。
- 联络读取必须按 Agent、联系人和 Session 精确保存最后一次成功快照：同作用域的临时刷新失败保留快照并标为可能过期，首次读取失败不得伪装为空；权限失效、资源不存在或作用域切换必须清空对应快照。恢复只由用户对失败阶段执行精确刷新，不自动重放请求，也不得改变发送命令和请求身份。
